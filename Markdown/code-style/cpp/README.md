# C++ 开发规范

本页是执行导航与评审清单。完整、权威条款见 [项目 C++ 编码规范](../../../CPP_CODING_STANDARD.md)，实际编码和评审时应阅读全文。

## 适用边界

- 适用于第一方新增和重写代码；存量代码随实际重写逐步迁移。
- 小范围修复只改必要区域，不扩大重命名或格式化范围。
- 第三方及上游同步代码保持上游风格；生成代码修改生成器或模板。
- 文件重命名、目录调整、全局格式配置和大规模迁移单独评审、单独验证。

## 核心检查

- 使用构建系统支持的 C++17，不使用异常作为错误处理机制；`auto` 不得隐藏整数宽度、容器、所有权或指针属性。
- 文件、类、函数使用规范规定的 PascalCase；变量和参数使用“小写类型前缀 + 语义名称”，输出参数使用 `out_`。
- 块级左大括号另起一行；所有控制块保留大括号，不把执行逻辑写在控制语句同行。
- 使用制表符缩进，指针和引用符号靠近变量名，`const` 放在类型左侧。
- 直接包含所需声明，不依赖传递包含；头文件和全局作用域禁止 `using namespace`。
- 明确类型宽度、`const`、单位、空值、所有权、错误传播、线程亲和性及异步回调生命周期。
- 优先使用引擎容器和所有权设施；第三方标准类型限制在适配边界。
- 不通过无差别自动格式化迁移存量代码，也不绕过现有检查或真实告警。

规范版本与详细示例以权威原文为准，本页不复制其完整条款。
