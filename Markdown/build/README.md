# 构建模块

本模块处理编译、安装、启动及独立构建边界。命令均以**实际选中的引擎仓库根目录**为工作目录，不直接以外层工作区根目录替代。

## 子模块路由

| 任务类型 | 子模块入口 |
| --- | --- |
| Windows 编辑器编译、安装与启动 | `windows-editor/README.md` |
| Engine Next 独立源码与链接边界检查 | `engine-next/README.md` |

## 通用约定

- 开始前确认实际工作副本、基线和已有未提交修改，不混用不同副本的命令与结果。
- 根据变更运行受影响的构建；纯文档变更不机械触发完整引擎编译。
- 构建日志必须绑定本次候选，不能用旧日志证明新改动通过。
- 编译成功、安装成功、启动成功和业务验收是不同事实，分别记录。
