# EngineCore 模块

本模块是引擎核心架构与迁移边界的顶层入口，承载核心公共契约、对象与资源语义、宿主适配及独立演进规则。

当前不预建空子模块。新增规范优先并入本文件对应章节；形成独立加载边界后再拆分，避免核心架构被拆成大量只有少量规则的目录。

## 当前路由

| 任务类型 | 入口 |
| --- | --- |
| AIChat、马良、天枢及新增 AINative 工作流的公共运行契约与 M/C/V 分离 | [AI 公共运行契约](../../ai_core/README.md) |
| 独立源码根、禁止依赖、链接输入与构建验证 | `../build/engine-next/README.md` |
| 第一方 C++ 编码与评审 | `../code-style/cpp/README.md` |
| 引擎接入、能力协议与迁移验证 | [引擎适配与迁移规范](../../framework/specs/engine-adapter.md) |

## 架构边界

- 共工持有的意图、实体身份、资产来源、任务、依赖和证据保持引擎无关；适配器负责映射到具体引擎对象。
- 中间表示只覆盖经过真实流程验证的共同语义，同时允许显式声明引擎专属能力。
- 每项引擎能力声明版本、支持范围和失败语义；不支持时明确返回差异，不静默丢弃数据。
- 场景、资源、组件、动画和物理迁移不仅验证格式，还必须验证可比较的实际行为。
- 新核心不得通过改名、包装、传递包含或链接输入重新绑定 Godot 实现；具体检查由 Engine Next 构建契约承担。

## 规则归属

- Gameplay 业务对象、会话、复制和预测进入 `../gameplay/README.md`。
- 编辑器 UI 语义操作进入 `../editor-control/README.md`。
- 编译、链接和构建产物证据进入 `../build/README.md`。
- 只有跨宿主的核心公共契约、生命周期和迁移规则保留在本模块。
