# 马良模块

本模块是 Agent 处理马良图像、Mesh、骨骼生成及对应验收的索引。具体规则只保留在下表命中的子模块中，本文件不复制正文。

## 子模块路由

| 任务类型 | 子模块入口 |
| --- | --- |
| 图像生成、图生／文生 Mesh、视觉 review、原模型增量修复与运行包验收 | [生成图、mesh流程](生成图、mesh流程.md) |
| 人物标准化、骨架生成、蒙皮、ROM／动画验证与角色版本发布 | [生成骨骼流程](生成骨骼流程.md) |

只加载当前任务命中的子模块；完整“图像／Mesh → 骨骼角色”任务按流程顺序加载两份细则。

## 共同约定

实现契约与参数细节以 [AINative 工具说明](../../tools/ainative/README.md) 为准；单次日志、调试脚本和历史验收记录只作为证据，不替代当前子模块。

涉及 UI 操作时同时加载 `editor-control/ui-commands`；修改代码后按 `testing` 选择回归；修改内置工具后按 `build` 完成运行包构建和安装。不得只读其中一个模块就把源码测试等同于业务验收。
