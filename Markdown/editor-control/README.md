# 编辑器语义控制与 UI 命令化

本模块把界面打开、定位、高亮、配置和文字输入统一为“**发现目标 → 声明式命令 → 权限与确认 → 原生执行 → 状态回读**”的受控流程。

## 子模块路由

| 任务类型 | 子模块入口 |
| --- | --- |
| 通用 UI 发现、文本／控件输入、按钮操作、CLI／HTTP 路由 | `ui-commands/README.md` |
| 官方受信宿主中的仅咨询文字命令输入 | `consultation-input/README.md` |

## 不变边界

- 不使用屏幕坐标或操作系统键鼠模拟替代语义操作。
- 不通过任意 GDScript、任意对象方法或修改代码绕过能力白名单。
- 只使用当前能力目录声明的目标和动作，不按界面显示名称猜测 ID。
- `planning_required`、`pending`、`awaiting_confirmation` 不表示已经执行。
- 用户拒绝后停止该操作；断线或超时先查询结果，不盲目重试写入。
