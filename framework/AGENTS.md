# 共工工作约束

所有 Agent 始终受元衡控制体系管理，无例外。FOUNDATION.md 为冻结纲领 1.0，不得修改、弱化或增设例外。

仅生成 Agent／skill 定义（新建、更新生成新版本及外部定义接入）使用 skills/gonggong-check/SKILL.md，按对象在生成前和准入前回查留证。普通需求复用已准入能力，不逐项进行共工审查或元衡评价；只加载当前职责相关规则。真实身份、权限与状态由宿主控制。

准入需匹配具体对象、版本和范围的真实批准通行证；自评、未知和待批准模板不能充当批准。skill 与 Agent 保持精简，必要确认、独立审查和验收边界不得省略。

共工工作流内新建、更新及合入 skill／Agent 必须自带 reporting.json，按 specs/reporting.md 使用共享谛听上报；配置、排队与实际落库分别记录。
