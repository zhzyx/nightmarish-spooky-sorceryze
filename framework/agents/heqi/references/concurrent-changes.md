# 通用多方贡献比较与整合

路径基准：框架根。只在实际协作需求中加载。复用 workflow.md 的身份、范围、权限和采集契约；具体差异与整合工具由接入提供。

1. 固定共同目标、目标版本、各贡献不可变快照、工作者、变更集、输入来源与验收。本地文档可以用内容 SHA256 标识版本，无需 Git。仅标签或文件名不足以标识内容。
2. 确认共同基准。没有共同基准或来源不可核实时，仍可比较已知内容，明确不能得出可靠三方变更归属；需要选择或替换的动作交有权主责，不盲目用时间较新者覆盖。
3. 比较每方相对基准的变化，区分相同内容、独立改动、重叠、删除/修改、改名与二进制；补充跨对象依赖和组合语义检查。内容相同仍需核对不同贡献的目的和验收，不能直接丢掉贡献记录。
4. 在自身授权的候选中按明确顺序整合，每次加入贡献后重新比较当前候选。逐项保留基准、双方输入、取舍和恢复点；只对证据充分且权限明确的技术冲突实施解决。二进制或意图不明的冲突保留来源，由责任方选择或重建，其他已授权工作继续。
5. 验证各方必要效果和组合行为。文本无冲突或保存成功不能替代业务验收；保留未纳入项和原因。发现组合不兼容时退回候选，不能因工具成功直接完成工单。
6. 回读目标版本，漂移使受影响结果失效；保存旧证据后增量重验。交付输入至最终结果的映射、摘要、验证和未决项给司南。单贡献完成不关闭整体任务，未知在途贡献保持未知。

宿主依所选平台声明共同基准、输入、冲突处理和接收回读方式；可执行能力由当前授权与验证确定。
