# 共工0.9.0跨模型改造

已实现独立于GPT/Codex的本地文本模型运行闭环，保留3个Agent和9项skill；冻结纲领1.0、元衡0.4.1及12个组件入口原文均不变。三个Agent版本0.4.0，八个本地skill版本0.3.0，上游组织skill原件不变。

## 实现

| 模块 | 可运行能力 |
| --- | --- |
| runtime/adapters.py | Chat Completions兼容、Ollama Chat、共工通用JSON；环境凭据、非流式文本、用量归一化及未知结果保护 |
| runtime/runner.py | 单步、宿主流程、受控资源读取；定义准入、HMAC委托、任务/模型/状态绑定、持久预算、去重、续期及中断恢复 |
| runtime/evaluate.py | 宿主提供代表任务、保留样本/配置指纹、记录通过的任务类型；模拟证据不可用于生产任务 |
| runtime/diting.py | 原账本及outbox自动记录本运行器中的需求、内部消息、步骤消耗、契约失败、返工、结束和覆盖缺口；skill调用只计一次 |

使用方式及字段见[跨模型运行规范](../specs/model-runtime.md)，计划模板见[model-plan.json](../templates/model-plan.json)。独立运行不依赖OpenAI SDK。实际服务地址、模型名、授权与评测需由部署者提供；本次未创建生产密钥或真实模型委托。

## 验证

独立运行29项、适配器11项通过；主任务补充10项本地HTTP/CLI集成检查，实际经过定义准入和谛听SQLite提交，覆盖三种协议及三个Agent入口。原上报24项、数据24项回归通过。共98项检查，不把它们称作98个真实模型任务。

复核修复了连续任务快照冲突、坏输出质量记录缺失、畸形用量污染队列、中断漏记已知用量、取消/完成状态冲突及委托到期无法恢复等问题。详见[运行审查](model-runtime-review.md)、[语义审查](model-semantic-review.md)及[发布核验](release.json)。可在框架根执行 `python tests/test_runtime.py` 重跑本地合成HTTP/CLI集成测试；测试批准和密钥仅用于隔离夹具。

## 适用边界

本次交付是模型中立的执行底座，不是“所有模型均已认证”。尚未配置真实模型服务，因此真实模型代表任务、供应商计量、业务有效交付和成本仍待验证。

当前仅支持文本非流式调用；自主模式只读取授权资源，不执行shell或写引擎。模型返回候选，业务验收仍归原质量责任链。生产IAM、多租户系统隔离、分布式调度、全局金额预算和企业高并发仍待建设验收；同状态目录采用单worker锁。

自动上报只覆盖经此运行器创建的调用链；没有接管全部Codex/引擎聊天。外部语义纠偏和业务质量事件需要宿主明确上报，缺口已标注，不以0冒充完整数据。谛听对共工/元衡仍只保留reference。
