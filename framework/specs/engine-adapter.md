# 共工引擎适配与迁移规范

版本：0.3。性质：专项规范草案。加载条件：接入或迁移游戏引擎时。

按需参考依赖：specs/module-system.md。仅加载与当前职责有关的部分；不要求每个执行任务读取全部依赖。

## 引擎接入与迁移

共工持有引擎无关的意图、实体身份、资产源、任务、依赖和证据。适配器负责实体与 目标引擎的节点、资源、脚本和运行对象的映射。中间表示只覆盖经过真实流程验证的共同语义，同时允许声明引擎专属能力。

引擎能力协议覆盖场景查询与修改、资源导入、组件绑定、动画与事件、碰撞导航、运行输入与观测、测试和构建。每项能力声明版本、支持范围和失败语义；不能支持时显式返回差异，不静默丢弃数据。


| 迁移对象 | 迁移方式 |
| --- | --- |
| 元衡原则、Agent 模板、工作流、企业配置 | 保持版本和契约，复用共同治理逻辑 |
| 意图、工单、资产来源、配方与证据 | 保留稳定身份，必要时转换数据版本 |
| 场景、材质、组件、动画、物理配置 | 按能力映射转换，报告不支持项并回归 |
| 原引擎专属脚本、Shader 与插件 | 预期适配或重写，验证行为而非只验证格式 |

AI 层可迁移不等于游戏工程自动迁移。先用代表性 Feature 在两个后端验证相同规格与可比较行为，再扩大范围。
