# 跨模型运行与能力准入

模型驱动的实例受元衡控制。执行前核验 Agent 定义准入、真实任务委托、授权工具和资源、有效期及预算。结果交由业务责任方验收。

按任务选择已经过代表性评测的模型。记录准确型号、接口、配置版本、评测范围、原始结果和不可变修订，区分模拟验证及真实服务。模型、接口、能力条件或证据改变时重新评测受影响部分。模型适配说明「可以完成什么任务」，接入适配说明「怎样安全调用并取得结果」。

上下文保留冻结纲领、元衡核心与模板、当前角色及真实委托，只加载当前步骤需要的资料。上下文超过已验证容量时使用获准替代模型或交给责任人处理。凭据保存在宿主权限边界内；模型输出必须通过当前任务的结构、工具和资源范围校验。

允许切换模型时，所有尝试共享原任务预算。结果未知或可能已经消费、写入时先对账。持久化任务身份、调用前事件、响应与用量证据、交接和恢复状态，防止并发或重试重复执行。已完成任务只补交回执。续期只由实际授权主体办理，范围、候选或预算变化另行核验。

共享谛听按实际执行者和步骤采集。记录保留在用户授权的范围内，缺失用量与外部覆盖保持未知。宿主另行声明协议映射、输出限额的保障范围、状态存储、恢复方法和验收环境。
