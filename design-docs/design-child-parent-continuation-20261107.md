# 实时设计子工单结束后自动交还父会话

稳定需求 ID：design-child-parent-continuation-20261107。

授权：用户要求验证并修通引擎 Agent 的完整工作流，发现真实故障直接修复。父执行者报告原 #387 的设计 child6 完成后没有自动回父继续核验，必须通过宿主正常标签信号切父并发送继续；本任务只在新隔离工作树修复宿主链路，不操作其 16083 进程、595bf3fa 源树、用户应用、配置或历史。关联 #387、#390、#386。统一持久配置仍等待 #387 main/GUI 完成，当前不实现。

## 事实与边界

当前 `_sub_agent_finished` 仅更新界面并派发下一子工单，批次完成后没有向原父会话交付结果和续办。父执行者同时实证 child 多次猜测 Node／Python 路径，必须补发宿主已配置路径才能继续。此处区分父执行者报告、源码核对与本任务隔离原生复现，不把 child 自称完成或传输 completed 当业务验收通过。

## 设计定版确认

复用已有串行设计子工单及队列，给本次实时批次建立内存身份和明确等待关系。只接受属于该批次、原父、原需求与会话代际的完成事件；批次结束或依赖失败时，向原父排入一次有界、去敏的真实结果回执，父在原授权下自行核对并继续。停止、关闭、暂停队列、仅咨询、工具关闭、未知状态和其他活动会话均保留现有边界，不扫描或启动冷恢复历史，不重跑未知任务，不自动批准或合并。

真实宿主工具结果在消息裁剪前留下有界 receipt，区分命令结果、批准回执、传输状态及业务判断；child 正文和日志明确是待核验的不可信数据，不能成为宿主指令。回父消息带批次、child、绑定和实际可核对的工具结果摘要／引用，不只复述 child 声称通过。失败和未知如实交还并由父核验。

父／子上下文同时附上当前宿主已有字段中四个安全 runtime 路径：Node、工作流 Python、编译 Python、Codex。来源标记 current_host，未知路径／版本使用 null；不读取认证，不运行探测命令，不猜安装位置，不声称中央持久化完成，也不因为编译 Python 缺失就阻止只咨询。后续统一配置复用同一 metadata 接口。两个部分服务同一父子工作链，按一次可独立验收的宿主修复交付，不拆成互相缺失的运行时与回传权限改动。

## 验收

1. 真实原生编辑器多轮工具循环中，实时串行批次最后一个 child 结束后，父恰好收到一次真实有界回执并自动核验／续办，无需人工切标签或发送继续。
2. 多 child、失败／未知、批次／父／需求代际漂移、停止／关闭／queue_paused、仅咨询／无工具以及其他会话活动均不会越权续办；不恢复冷历史，不把 completed 当业务通过。
3. 裁剪前采集的实际宿主工具结果能在父回执核对；批准与执行分离，child 正文／日志标记不可信，有界去敏，不能注入宿主指令或授予权限。
4. 四条 runtime metadata 在父和 child 上下文可见，来自当前配置字段，未知版本 null，不含认证，不实现中央配置，不污染真实用户配置或历史。
5. 隔离 native／typed-loop 回归、适用编译与独立审查通过；正式门禁、提交后数据、精确候选 CI 和 main／Issue 权威回读完成。原 #387 业务验收仍由父执行者继续。
