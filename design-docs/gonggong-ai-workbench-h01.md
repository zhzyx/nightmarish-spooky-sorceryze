# H01 创意判断绑定发起人、责任人和产物修订

创建创意判断项时服务将工单发起人保存为默认责任人。读回每一提交的独立修订、责任人和决定，工作执行人员可提交产物，判断操作检查已绑定的责任人。旧提交使用工单的原始创建者读回责任，原始历史事件保持可审计。

## 转交与本人待办

[H02 转交创意判断责任](gonggong-ai-workbench-plan1.md#h02)和 [H03 显示本人的待判断事项](gonggong-ai-workbench-plan1.md#h03)以工单和产物提交序号定位一次判断。转交前核对当前责任人、工单版本及接收人对工单、来源设计和产物的权限。事件保存双方、意见与提交序号，旧页提交时重新核对责任和版本。采纳较早修订只更新该项，后续产物的当前确认状态独立。

登录原生工作台后打开「我的待判断事项」，按当前项目和业务身份读取待办。选择一项会打开原工单及其多宝提交详情，保留原始设计和已有意见的入口。关闭提交详情后可填写意见、转交另一位有权处理的成员，或采纳、退回所选修订。
