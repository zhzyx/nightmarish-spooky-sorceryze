# M4.3 点光、聚光与 PCSS 分片

本分片继续 #1343 与父单 #1323，基于方向光及网络诊断候选 3e5ed09f33cb6eaa94a3021e14ba9b5cd71e1b97。对应签发 PR #1350 的 macOS 重连问题由 #1349 跟进。

## 设计

RenderConfiguration 可选点光、聚光数组各最多四盏，显式稳定标识、米制位置与范围、光通量、颜色、投影开关。点光六个透视视图使用 2D array，采样按偏置后的点选择主轴面并使用同一面矩阵。聚光使用独立透视矩阵，保持现有配置的数值范围。光源 ID 跨两种数组唯一。

LocalShadow 作为独立 FrameGraph pass，最多 28 层深度视图，每帧单独资源与上传常量。PCF 使用 3×3，PCSS 使用固定 5×5 blocker search 与过滤，反向深度先重建为线性光源距离，半影半径限制为 32 texels。光源几何半径通过透视投影转换，极端参数在 GPU 表示无法成立时返回诊断。

点光过滤以世界方向切平面构建采样核，每个样本重新选择立方体面，按实际纹素中心射线恢复径向遮挡距离。几何接收平面用于逐样本比较，导数在光源循环及天空分支前计算。聚光按弦长平方 smoothstep 的实际有效立体角换算光通量。#1351 记录了推动这些修复的压力场景接缝和光通量缺陷。

极窄聚光采用弦长平方表示内外锥，避免浮点余弦合并。GPU 法线与方向归一化、近光照衰减、有限辐射及半精度输出上限共同防止非法颜色传播。

## 验收

各面正交、近远平面反向深度、聚光锥边界、ID 与数组上限、无效输入事务性均测试。实机检查点光阴影六面、聚光范围、PCF/PCSS 软边变化、MASK/镜像、禁用回退、灯光移动和配置回退。采样代码通过同一 HLSLI 的 CPU stub 与 DXC 验证，GPU capture 复核真实资源与调用。

虚拟阴影页缓存、完整大场景性能、时域处理、反射、体积与透明继续后续分片，父单最终 UE 与原生 4K 验收保持开放。
