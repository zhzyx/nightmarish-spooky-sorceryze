# Bug：马良真实生成服务无法在引擎内完成配置与验证

<!-- gonggong-request:maliang-generation-service-setup-bug-20261107 -->

## 用户报告与授权

2026-11-07，用户在马良“图像生成网格”节点点击“运行并预览”，界面仅报“操作失败：创建运行（源文件未改动）”。只读排查后用户明确要求：“那这件事在引擎里就没闭环，要当bug来改”。本单记录该缺陷及修复验收；旁支与主对话 #411 的执行交接尚待用户选择，不抢占其在途文件或安装包。

## 已核实事实

- 本机设置仅提供 Python 路径、脚本路径和字符串形式的生成服务入口，缺少可完成真实服务配置、连接检测及模型选择的完整界面。
- 默认 editor_demo:factory 只注册离线 copy 节点，却允许创建并尝试运行 ComfyUI 图像/网格生成节点。
- comfy_provider:factory 从进程环境的 AINATIVE_COMFY_CONFIG 读取外部 JSON，GUI 启动编辑器不能仅凭已保存的界面设置完成接入。
- 当前工程未保存 local.cfg，启动环境未设置生成服务配置；运行数据库中没有成功创建的运行记录。未读取到本次被吞掉的原始异常，因此最终失败链仍需在修复时定向复现，不能仅凭截图断言缺图或模型错误。
- editor_host.py 将创建阶段异常统一转换为 editor_command_failed，界面无法区分未配置服务、缺少源图、模型缺失或服务不可达。

## 修复目标

1. 在“马良 → 本机设置”中完成真实生成服务的配置、保存、检测与重开恢复。用户能选择服务类型、填写服务地址、选择当前可用模型，并获得明确的就绪状态。必需模型信息提供选择/检测或可操作引导，避免要求普通用户手工拼 Python factory、环境变量或配置 JSON。
2. GUI 保存的本机配置直接传到生成服务适配器，独立于编辑器启动方式；从 Finder 启动、重启编辑器及内置工具升级后仍生效。可兼容既有环境变量/配置，但不能把它们作为唯一入口。保留配置与工作流数据分离，不把凭据写入工作流或公开日志。
3. 区分离线演示与真实生成能力：未接好真实服务时不得把生成节点呈现为可正常生成。点击运行时明确指向具体缺项及配置入口；离线复制继续可用。
4. 执行前检查节点类型需要的输入、所选服务能力、模型和连接状态。源图缺失、服务未运行、模型不可用、版本/配置不匹配等须显示具体且可修复的中文提示；保留经脱敏的诊断原因，不只显示“创建运行失败”。
5. 连接检测不偷偷触发模型推理；生成仍由用户明确点击触发。不要自动下载大型模型、改变已有模型选择或伪造连接/模型可用状态。

## 验收

- 从无生成配置的工程开始，在引擎界面完成设置、检测与保存；无需终端环境变量；退出后从 Finder 重开仍可读取同一配置。
- 在同一安装版编辑器中验证真实服务的“配置 → 节点输入 → 点击运行并预览 → 返回真实结果”完整链路；覆盖图片及网格能力。仅离线复制、接口桩或配置文件存在不能代替真实生成验收；若模型/设备不可用，须保留具体未验收项，不能将本单标完成。
- 未配置、错误地址、服务离线、模型缺失、图像输入缺失、不可用节点类型均有准确提示，并能按提示修正后重试。
- 离线复制、旧配置兼容、工作流保存重开、取消、防重复提交、历史预览与发布回归通过。
- 与 #411 右键改造协调共享工作台文件；不覆盖其候选或抢先替换用户正在使用的安装包。完成后按已确认执行责任更新同一马良安装版并复核。
