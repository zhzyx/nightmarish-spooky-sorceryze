# 原生执行节点与服务器协调

需求 ID：native-remote-execution-20261118，父 #1444。路径基准为仓库根。原用户已授权服务器协调、复用本机或既有执行节点，不以 Git/worktree 作为运行时合作协议。

当前已审查的 #1466 链路只支持同一协调器的本地工作者。新增真实远端工作者适配：服务器保留组织、需求、任务、不可变内容、当前授权、候选接收与验收；节点保留已安装CLI/构建工具、凭据、精确输入缓存和真实进程记录。保留司南模型路由与合契/阎罗分工。

1. 可信安装者登记节点身份、租户、精确包/工具/profile摘要、能力和实际容量。请求不能自报另一租户、producer、argv、env或安装批准；节点认证与用户认证分开，机器凭据不能变成通用平台管理员权限。
2. 服务器短事务固定 task/execution/node/profile/installation/输入摘要和容量占用；真实进程启动、网络传输、模型/检查在锁外。没有可用节点时明确容量等待，不造成全局长锁、反复模型规划或无限隐形队列。
3. 节点主动建立认证事件等待，适配NAT，不开放本机执行端口。使用持久事件游标和提交唤醒，关闭注册/读取竞态；传输重连是恢复，不做定时扫描工单。初版单协调器，进程外唤醒未实现则明确拒绝，不假装支持多服务进程。
4. 固定输入按模块清单和内容摘要传输，仅补缺失对象，使用节点独立存储和有界普通文件物化；不共享服务器SQLite、不复制全仓库或凭据。输入/输出/文件数/队列/磁盘有界，不能把所有250任务内容同时放进服务器内存。
5. 节点持久记录接收、启动意图、真实进程所有权、物理关闭、收集输出及传输回执。重复请求只回读原结果；启动结果不明保留原占用，不按PID/租约超时接管或自动重跑。模型输出与节点自报的任意JSON不构成可信终态；服务器只接收已准入执行节点对精确任务的回执。
6. 物理关闭与内容可验收分离；producer撤销后可信节点仍可证明物理关闭释放资源，内容接收/依赖放行须继续核对当前权限。取消请求不等于已停止；验证整个进程树真正关闭。当前原任务换版、跨组织、伪造节点、重复键不同内容、损坏/超额/别名输入输出拒绝。
7. 接收候选与工作流推进之间失败可凭持久键回读恢复，同一产品原始贡献不被覆盖，完成事件接续实际联合检查/独立发布/需求进度/下游。断网及服务器/节点重启不重复生产，未知状态明确列出恢复责任。
8. 本地确定性测试必须使用独立的服务器/节点数据库和真实生产进程，覆盖双认领、容量/公平性、重连/损坏/撤销/取消及接续。根责任者继续在现有服务器隔离部署、Windows节点跨机器实测、250在途与真实模型评测；单机fixture不宣称完成这些验收。

此为已有sinan-workorders/server宿主模块扩展，不新增框架角色/微服务集群。普通同用户进程不具备敌对程序OS隔离：初版只允许可信安装的执行程序，明确节点可信边界；节点凭据和journal不发送给模型。具体配置由宿主绝对路径解析且不入库。回退停用入口并保留账本/回执/未知占用，完成真实备份恢复后再切换有效安装。新增源码按host_tool验证真实SCons与缓存边界，独立审查及main留底后交付，不削减渲染能力。
