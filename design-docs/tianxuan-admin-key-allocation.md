# 天璇管理员密钥分配

在天璇「账号与访问密钥」提供管理员专用的分配界面。管理员选择本租户已有管理员、密钥用途和有效期，签发属于收件人的个人访问密钥。新增管理员和调整成员角色沿用账号管理。签发时由服务端核对操作者、租户和收件人的当前角色，保留既有密钥撤销与审计记录。

验收覆盖管理员分配、收件人登录、撤销后失效，以及普通账号、跨租户和已降级收件人的拒绝结果。明文只在签发响应及当前交接界面出现。

[跟踪工单 #2111](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/2111)。从账号页打开「分配管理员密钥」可到达 `/accounts/admin-keys`。密钥用途用于在已签发列表识别和撤销；有效期可选 1 至 365 天，默认 90 天。
