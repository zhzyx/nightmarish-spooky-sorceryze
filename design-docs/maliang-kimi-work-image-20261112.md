## 目标与授权

用户明确要求“那马良的文字生图、图生图你都接一下”，并在此前要求通过 Godot 马良现有编辑器工作流运行与展示。本次负责实现、必要回归、真实图像生成、原生编辑器预览及仓库交付流程。授权来源为用户当前对话中的上述明确请求；本文件只记录需求，不把临时截图或宿主凭据写成运行依赖。

## 服务边界

保留 `kimi_native` 现有 Mesh 路线：Kimi 所选模型生成严格建模计划，固定 Godot 构造器生成网格，不改为图像扩散或 ComfyUI。

在同一个 `kimi_native` 服务模式下增加复合路由：`text_to_image` 与 `image_to_image` 使用独立 `kimi_work_image` Provider，经用户配置的 Kimi Work `image_generation_tool.py` 和受支持的无窗口 Python 运行环境调用 `agent-gw generate_image`；Mesh 节点继续使用 `kimi_native`。二维服务与 K3.1 Pro 建模模型分别标注，不声称 K3.1 Pro 直接输出二维图片，也不将其他图像服务改名为 K3.1 Pro。

二维服务路径由本机设置或环境提供，不硬编码某台机器的安装位置。凭据继续由 Kimi Work SDK 的既有凭据链管理，不写入节点、设置、工作流、公开日志或 Git 证据。图生图先将本地输入通过官方 `image-to-url` 转为参考 URL，再调用生成；URL、原始日志、请求与响应只留在私有任务存储。

## 实施与验收

- 配置、检测与能力报告分别覆盖二维与 Mesh。二维不可用不能掩盖已就绪的 Mesh；缺失配置给出可操作的错误。
- 新增图像任务 Provider，复用现有 Executor 的持久意图、幂等、取消、轮询、恢复和不可变终态。Windows 遵循插件无窗口 launcher/watcher 合同；未知回执、超时或网络失败不自动重新生成。
- 图生图保留有效提示词与有序多源引用；文字生图、图生图均支持明确数量或“视角／变体标签”列表，每次 1～8 张。每张图分别生成、校验、留回执、预览和选择发布；一张多视图拼板不能冒充多张输出。
- 流程层统一适配 Kimi Work、ComfyUI、Codex 等 Provider：原生多参考模型接收全部有序引用；单图 Provider 接收带 `REF 1…N` 标签的确定性多源参考板，不静默丢弃输入。来源记录必须区分两种适配，不声称各模型原生能力相同。
- 新增版本 2 图像节点与 `image_set` 集合 artifact，保留 `result` 主图以兼容旧 Mesh 连线；版本 1 节点定义及旧运行恢复不变。集合记录有序成员、标签、来源摘要和适配策略，发布时验证所选成员属于该集合。
- 每个输出使用独立幂等键和持久子任务；父任务只有在全部成员通过校验后才成功。未知回执只恢复原任务，不重复上传或生成，部分失败不删除其他子任务回执。
- 源图像与参考图像通过系统资源管理器选择，普通界面不要求手输绝对路径；选择后沿用既有节点字段、应用、保存与生成契约，并可清除选择。图生节点仅筛选 PNG/JPEG，离线复制仍支持 GLB／内嵌 glTF。
- 接受的新结果必须是本次任务产生且通过完整 PNG/JPEG 解码校验的新文件；记录格式、尺寸、字节数、输入／输出 SHA-256、Provider、图像生成版本及私有回执摘要。编辑结果不得等于源图，旧图或复制输入不算成功。
- 参数界面提供实际生效的宽高，图像采样、随机种子、denoise 等未应用参数不得伪装生效。
- 更新 Python 协议测试、设置恢复及 GUI 测试；使用本地假工具与固定图像，不在单元测试中发起真实生成。
- 沿 `editor/SCsub`、内嵌工具清单及原生 Workbench 消费点确认构建边界。新增 Python 源若为嵌入输入，重建 Windows x64 编辑器并验证新功能与重开恢复；旧二进制不能作为新功能已验收的证据。
- 在真实 Godot 马良中各运行一次文字生图和图生图，图生图使用同一中性雕塑的两张独立视角源图，生成“正面”“三分之四侧面”两张独立输出；保留运行 ID、各成员 SHA、来源摘要及实际编辑器逐图截图，选择第二张发布并验证重开恢复不新增上传或生成。采用中性测试提示词，不把用户用于说明功能的截图当作素材。ComfyUI／Codex 若只执行本地假 Provider 验证，明确记为未做真实多图推理。

## 范围、平台与停止条件

目标平台为 Windows x64、Python 3.11+、当前定制 Godot 4.8 编辑器。本次不替换既有 Provider，不扩展为视频、无界批量队列、自动绑骨或训练模型；仅支持每次最多 8 张的有界多图生成，不承诺图像服务的具体生成质量、额度或耗时。
