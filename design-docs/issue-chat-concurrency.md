# 天枢工单并行对话

[工单 #723](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/723) 要求工单 A 等待回复时能向 B 发送消息。两个工单分别保留草稿、历史、运行与取消状态，回执归属实际发起的工单。

原有的 AI Chat 标签能保存暂停的会话。已有运行占用主对话时，天枢按已核验的工作区、仓库、账号、工单和需求创建独立执行实例。切换工单只挂载目标聊天控件。各实例拥有自己的请求、计时器、CLI 会话和续跑日志。独立历史位于当前 Godot 项目编辑器设置目录下的 `tianshu_workers/<绑定摘要>/`；已有会话的文件快照按原位置和会话身份读取。正在承担子任务依赖的旧会话保留在原执行者上。

验收通过静默编辑器和隔离的回环模型端点，先创建 B 的草稿，再让 A、B 同时抵达服务端且保持未返回。切回 A 取消，核对 B 仍可返回自己的答复。重启后重新打开原始两张工单，核对独立会话和草稿。普通开发路径使用两个真实临时 Git 候选、隔离的工单服务和本地模型服务。服务端同时收到两个请求后才返回相同的命令提案，交换确认令牌应被拒绝。停止 A、批准 B 后，检查只有 B 的候选写入执行结果，同时逐单回读取消和完成事件。
