## 范围

新增原生引擎设置主页，提供“AI”“环境”两个明确分类。AI集中聊天后端、模型/推理配置、接口与账号接入，以及马良的生成服务、图像/网格模型与检测。环境集中Python各用途、Node.js、CLI及桥接路径、本机模型运行库与启动管理。天枢的模型接入配置同步归到该入口，复用现有模型库与系统凭据规则。

业务页中的配置入口统一跳转并定位设置分类，实际编辑控件由设置页单一承载，不复制一套会失步的表单。保留既有配置值和持久化兼容；共享的同一运行时配置保持一致，用途确实不同的运行环境明确标注角色。提示词、生成参数及当次执行授权作为任务输入，不混成全局默认授权。

配置变更继续遵循在途任务快照、连接检测只读、未知结果不自动重试、凭据不进入工作流和公开日志的现有约定。迁移或集中设置不会自动发起模型推理，不增加账号与付费入口。

## 验收

1. 任意无addons工程可打开原生“设置”页签，AI、环境两栏及中文操作完整可用；可从AI Chat、马良和天枢跳转到同一页。
2. 原业务页不再承载可编辑的模型/服务/运行环境配置；设置页操作真实原有控件/配置源，切换业务即时使用正确设置。
3. 旧设置保留，保存及重开生效；CLI、Python等共享配置不出现两处可编辑且失步的副本，独立用途保持明确角色。
4. 服务与模型检测、缺配置引导、运行中锁定/快照、模型列表及本机运行库管理行为保持；检测、切换页签及保存不会触发付费生成。
5. 以隔离编辑器的真实控件/信号、持久化与消费者回读验证，覆盖重开、缺项、在途设置和旧入口导航；必要编译、独立审查、精确候选CI/main及工单关闭回读完成。

## 使用入口

编辑器主屏幕的“设置”页签提供两个分类。“AI”包含对话与 Agent、图像与 Mesh 生成、个人模型库；“环境”包含聊天及工作流运行环境、引擎编译环境、美术工具和本机模型运行库。AI Chat、马良与天枢原入口仅导航到对应分类。

统一页承载既有实际控件与配置源；原有保存位置兼容。引擎编译 Python、共工工作流 Python、美术与模型 Python 以及不同用途的 CLI 路径独立标明，不静默覆盖既有值。个人模型库仍需核对工作区身份，聊天密钥仅属于本次会话；提示词、资产与本次生成参数保留在业务工作流。
