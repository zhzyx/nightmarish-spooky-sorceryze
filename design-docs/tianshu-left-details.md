# 天枢左侧详情视窗

对应工单 #665，需求 ID 为 `tianshu-left-details`。

## 范围与验收

- 进入单个 Issue 时，流程图旁默认显示当前工单链接、状态、偃师设计文档和关联工单状态。关联列表覆盖父子、依赖、被依赖和工单引用，包括已关闭工单。读取失败时显示实际未核实状态。
- 选择流程板块后显示其当前状态、内容和前后相连的板块，可以返回同一工单的文档。
- 允许在天枢内编辑绑定的 Markdown。保存将修改写入当前工作区对应文件，撤销修改恢复当前编辑基线。切换工单时隔离未保存的文字。保存前重新核对身份、工单和文件版本，发现冲突时保留编辑内容。
- 宽窗在流程图左侧显示详情，窄窗上下排列。原操作确认和聊天入口继续可用。
