# 马良参数表单与开发者 JSON 分离

用户授权：2026-11-07 当前侧对话先询问“参数json有必要暴露给用户么？”，确认建议后要求“落地”。将原始参数 JSON 从默认界面移入显式开发者选项，正常用户通过提示词、尺寸等表单配置生成参数；较少使用的采样/网格参数折叠；离线复制的 delay/fail 测试参数不出现在正常界面。内部工作流和参数 JSON 契约保持兼容；旧数据、未知键及参数精度不得因表单加载而丢失。开发者模式通过本机设置启用，原始 JSON 编辑与表单双向同步，非法值阻止应用而不改写节点。

范围：马良节点工作台及一个独立参数表单脚本、相关后台验收与说明。目标 macOS arm64，使用实际 GDScript 控件信号检验默认隐藏、各生成类型控件、切换/保存重开、非法输入及既有离线运行/预览。构建内置 bundle 并验证无 addons 编辑器入口。当前侧对话禁止子 Agent，不启用代理派发；独立审查如无法取得保持待核实，不虚构回执。

与 #411 右键操作改造共享工作台入口但职责不同：本单仅处理参数表单，不改画布操作入口；与在途 #393 引擎激活机制隔离，不操纵他人的工作副本或发布状态。停止条件为可审阅候选、必要验证及合法交付流程的真实回执。

工单：https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/413。实现已完成：类型适用的提示词、宽高、高级设置；本机开发者模式下的原始参数；旧参数和大整数精度保留；非法输入阻止应用。36 项新表单、35 项旧交互、35 项节点预览、152 项内置编辑器与打包检查通过。已整合 1d080f65 的激活工具主线，受测输入未变化。独立审查尚无真实回执，因此候选交付待审，不切换共享有效编辑器。
