# 多宝输入定址的验证证据缓存

需求 ID：duobao-native-evidence-20261117。父需求 #1382 的 P0-C 第一步，依赖 #1386 精确原生存储契约。

以可信宿主提供的检查规范、工具链、环境、参数及真实输入内容形成验证键。明确对象范围的检查只绑定实际对象摘要/缺失状态及相关精确依赖；同模块不相交内容或无关模块变化不能作废其证据。未知读取范围则绑定整个模块/组合，拒绝把未知当独立。模块修订 SHA 本身不能无条件充当所有检查的缓存键，否则只是将 main 重验缩小到模块。

实现新宿主文件与正常 CLI/API 库接口，复用原生数据库与精确组合。证据不可变，包含真实检查执行者、结果、原始证据摘要与规则/环境身份；持久存储、重启读取、幂等回执、租户隔离、损坏拒绝及显式撤回。可信宿主负责认证检查者与读取范围完备性，缓存不自授批准，不将提交者提供的 passed 布尔值当独立验收。未建立可信检查规范和执行者时拒绝接收证据。

验收：在同一模块的对象 A 验证后提交不相交 B，A 的验证键不变且能命中原证据；修改 A、读取缺失对象的存在性、依赖、检查版本、工具链、参数、环境任一变化均不能误命中。失败/未知/撤回证据不能作为通过返回；其他租户不可读；重启与重复回执保持一致。缺少范围按完整模块或组合保守处理。测试输入/规则/真实运行命令留证，记录调用次数和命中，不估算 token 或模型费用。

此子项只实现缓存和证据事实，不实现生产发布或自动签发；独立验收、发布清单和回退为后续 P0-C 子项，不缩减父目标。placement=host_tool，无 Git、网络、模型和引擎链接依赖；绝对数据库路径由宿主选择，停用入口保留证据作为回退。

## 实现与验证

`native_evidence.py` 提供可信宿主库接口，策略与读取范围由宿主安装。证据键绑定对象内容/缺失状态、精确依赖、规则、工具链、环境和参数；最新版失败、未知、过期、撤回或执行者授权失效不回退到旧通过。数据库事务保障证据与幂等回执原子写入。独立审查未发现可复现缺陷：16 项测试及 5 项补充检查通过；现有 Linux 服务器 Python 3.12.3 隔离运行同一 16 项测试通过，临时目录已清理，服务配置未修改。证据见 `data-collection/duobao-native-evidence-review-1406.json` 与 `data-collection/duobao-native-evidence-server-1406.json`。

这不是线上身份接线或真实检查执行器；声明读取范围完备性仍由可信宿主保证。没有生产容量、token 收益、发布授权或 AA 渲染验收结论。
