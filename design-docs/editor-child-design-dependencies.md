# 校验子工单派发的定版授权与业务依赖

设计定版派发绑定真实确认人、文档版本与工单。待批准标题不能触发生产；存在业务依赖时核对前置验收证据才继续。保留无依赖工单、去重、恢复与明确用户操作。验证草稿、版本漂移、前项仅传输完成与有效交接。

## 编辑器操作与证据

父会话检测到「设计定版确认」及生产工单列表，或操作者点击「按工单落地」时，编辑器显示工作副本、Issue、需求 ID、设计文件 SHA-256 和工单标题。操作者核对后点击确认，宿主从本地交互会话记录操作者与该版本的绑定。确认期间变更文件、派发前变更版本、旧子会话缺少该绑定时，重新核对原版本或关闭旧子会话并为新版本重新定版。

工单正文支持「依赖：无。」「依赖：工单 1、2。」和「依赖：工单 1–3。」。引用必须指向已列出的工单编号。串行和并行入口均检查依赖。在前置子会话点「验收当前工单」，核对所示终态回执，填写实际实测结果与证据位置。宿主将操作者、说明与原回执摘要写入子会话历史，并在后继启动时重新核对回执。冷恢复后可在父会话点「继续落地」。

并行工作者在派发副本和实际执行副本验证同一设计摘要，回执和持久工单票据绑定 Issue、需求、文档编号及该摘要。相同编号的旧版本票据须先对账。完成后只读咨询保留原验收证据。手动重新执行建立新批次，后续验收绑定新回执。
