# 编辑器整体布局与交互优化

用户于 2026-11-12 在 Codex 反馈“现在界面布局又丑又难用，优化交互”，并明确范围为“整个编辑器的布局”。当前会话负责实现、静默验证、独立核查、PR 与 main 交付。

目标：编辑器顶部按全局菜单、工作区导航和运行/配置操作划分层级，窄窗口仍能找到全部工作区；中央内容优先，场景编辑保留场景树、检查器和底部工具，AI/天枢/马良/设置页面继续使用完整工作区；支持可发现的专注与恢复操作。统一设置按任务分区，避免把所有模型、环境和生成服务堆在同一长页；常用连接操作、当前模型与状态在首屏可见，键盘导航与主题缩放可用。

验收：1. 顶部导航在常规及窄窗口无重叠，所有工作区和运行入口可到达；2. 场景与全屏工作区切换后，侧栏和底部面板可正确恢复，专注模式有明确开关；3. 设置有清晰分类、当前选中反馈、合理阅读宽度和滚动，现有设置控件与保存/运行行为完整保留；4. AI 配置入口和真实连接状态可用；5. 新布局遵循编辑器主题与缩放，后台控件信号、几何、重启和原有回归通过。

执行边界：基于当前远端 main 的隔离工作树，整合本会话 #828 的已审查 AI 配置候选，保留其工单及待交付状态。本次调整编辑器框架及统一设置的信息层级，不改变 2D/3D/脚本编辑功能或他人正在开发的天枢业务流程。目标平台 macOS arm64/Clang；使用候选原生构建与 --headless 隔离项目验证，不操作用户桌面。真实显示器像素审美与焦点效果无法用 headless 证明，交付时明确证据边界。所有路径以仓库根为基准。

分工：当前责任者整合与实现统一设置；司南按原生宿主协议派发独立的编辑器导航/布局工作和只读核查，明确写入范围。原 #828 与 CI 阻塞 #833 保留，不把新工单或本地通过作为主线交付回执。

关联工单：[#846](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/846)，验证故障跟踪 [#848](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/848)。已整合主线 `c811b583d4f709f697161280ed285c08793c90ef` 的蓝色波纹入口；#828 原候选作为本会话已授权贡献一起整合，旧证据保留，新候选证据以 `data-collection/editor-layout-846.json` 为准。

已实现：上下分层的全局工具栏与工作区导航；窄窗口原生标签溢出及全部工作区菜单；专注/恢复按钮；跨完整工作区切换保留底部面板和侧栏状态。设置分为五类，宽窗口侧边导航、窄窗口分类选择；业务入口直接进入对应控件所在页；当前模型和连接动作集中在首屏。设置内容使用工作区内滚动，长表单不会因期望尺寸扩大整个编辑器。
