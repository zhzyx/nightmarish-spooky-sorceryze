## 单 Issue 图编排

允许从节点菜单添加文本、图片、待答、Agent/模型任务和结果汇总。数据与执行端口的标签、形状不同。个人布局独立于执行图。草稿可暂缺输入，拖动时提示拒绝原因；应用时以该 Issue 的最新图修订、运行状态和操作者权限校验整组改动，冲突保留草稿。拒绝跨单、自连、重复、类型不符、数据或执行混合环，以及拆除必要验证、批准、交付链路。运行中和已完成节点的输入受保护，可供新的下游使用。成功应用产生一次真实事件，由司南复核就绪任务。

## 模型与执行

首版覆盖 Claude、DeepSeek、Gemini、GPT 的真实服务、所选供应商原生协议及自定义 OpenAI 兼容端点。每个节点每次调用一个模型。司南先筛能力和可用性，再按对应型号和任务类型的实测成绩选择，参考 Issue 偏好；没有评分时说明宿主偏好回退。手动覆盖仅作用于节点，可恢复自动。API 配置可现场新增并在本机复用，凭据由 macOS 或 Windows 系统安全存储。运行中改选可下次生效，或确认停止后另起一次调用，保留原始运行身份及结果。

独立分支和不同 Issue 按容量、依赖和资源互斥并发。每次 Agent 调用隔离上下文、请求、取消、结果。汇合等待全部必要前置，待答和取消只影响相关分支。验收要求跨供应商真实请求时间重叠，单分支独立取消，对账后再恢复；四家分别串行成功不能作为并行证据。
