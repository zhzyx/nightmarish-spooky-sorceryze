## 候选版本的正常生产入口

以下流程对应 #810/#821/#820/#845 的组合候选，须完成最终安装验收后才作为有效安装的使用说明。连接已有账号与 CLI，在模型列表中选择实际可用模型；打开“授权自动准备并行生产”，按账号和机器资源填写并行容量。普通游戏仓库保留自己的 Git/Issue 与需求数据，编辑器工具及框架从可信安装加载。无需用户手工建立工作副本、作业、注册表或并行配置；高级自定义配置仍按 [CLI 配置](../tools/godot_parallel/README.md) 兼容，显式配置优先。容量不代表供应商额度或已达到最优吞吐，凭据由原 CLI 管理。

在原父会话给出游戏目标、关联工单和可验证标准，定版工单逐项包含 `验收: ID | 可验证要求`，然后执行“按工单落地”。完成、独立验收、依赖补位和明确失败修复由实际事件接续；需要人决定的内容仍保留给有权人。

需要持续场景、资源、导入、运行和游戏输入操作时，打开“授权当前任务”；授权绑定当前项目、工单及会话，停止、撤销、切换或冷启动后重新核对。独立审查通过后，父会话从实际生产结果生成整合计划、应用成果，再读取真实运行调试信息并修复复验。历史记录和回滚记录可恢复，历史验收不自动取得新一轮执行权限。
