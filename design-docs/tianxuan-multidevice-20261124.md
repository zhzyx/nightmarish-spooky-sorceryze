# 天璇同账号多设备授权与提交归属

用户于 2026-11-24 在当前 Codex 会话明确授权实现：允许多个设备同时登录同一账号并执行提交，记录设备号及提交内容，防止提交冲突与鉴权标签重叠。当前责任者负责实现、验证、独立审查与正式交付。

验收：同一账号的两个独立设备登录均可有效操作；服务器生成并绑定独立设备号与授权标识，客户端提供的标签不成为身份；撤销一台设备不影响另一台，撤销来源授权后派生设备失效；多宝提交回执绑定账号、设备、请求号、基线、变更内容摘要及结果修订；同设备重放幂等，不同设备的同请求号隔离；交叉写入拒绝覆盖，无交叉变更可安全合并；现有租户、角色与会话约束保持有效。使用 Python 服务测试与并发数据库测试验证，客户端仅对实际改动执行对应检查。

范围为现有天璇身份服务及多宝原生提交入口，不增加框架定义或新模块。本任务交付可构建源码及实测证据。#2183/#2184 的持久身份已通过 #2198 合入 main，其后 #2205 补齐同账号既有设备授权留存；本候选继续整合 `2ec392e8cf654576dbf6f77ea53eb16211efdf67`，保留永久授权、系统凭据库及 CAS 保存。生产发布仍由原责任者持有，本任务不接管在途安装与配置。
