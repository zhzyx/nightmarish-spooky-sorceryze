# U10 把文档段落作为消息引用

在工作台打开天璇设计文档，选择段落后点“引用此段”。正文中的引用保存文档 ID、当时的内容版本和从 1 开始的段落序号。空行划分段落，同段内的换行保留。发送时天璇根据当前账号核对该文档的访问权限，并在指定的历史版本内检查段落存在。已有仅带文档和版本的消息继续按原格式读取。

在会话内打开“消息中的文档段落”，编辑器使用已发送消息的快照重新定位。后来编辑、移动段落或切换当前版本，都可以从该菜单读回发送时的原段落。

回归通过真实 Windows Godot 无窗口编辑器和启用身份验证的天璇服务执行。原生表单发送版本 1 的第 2 段后，服务端把这段移到版本 2 的第 3 段。测试同时核对持久化消息和从该消息重新打开的版本与段落。
