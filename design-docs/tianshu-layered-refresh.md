# 天枢按层级增量刷新

需求 `tianshu-layered-refresh` 对应 [工单 #524](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/524)。用户要求当前层级及时反映进度，后台层级合并变化并缓存数据，切换视图时分步呈现工单。

## 刷新与授权

本地回执事件携带的需求或工单标识用于定位行。前台处理当前可见范围的变化，后台合并同一层级的失效通知，只更新该层的数据缓存。定向读取和手动完整读取均以已核实的工作区、账号和作用域为准。账号切换、撤权、查不到来源以及旧响应到达时按实际身份、范围和请求代次处理。

## 界面与验收

- 总览列表和依赖图按工单 URL 对照快照，沿用未变的行、卡片和连线。验证新增、修改、移除、分类排序、筛选、负责人分区及依赖变化。
- 首次创建较大的图和列表时分帧处理，优先可见范围内已经定位的卡片。检查首批内容先出现、连续切页停止旧投影、隐藏视图仅更新缓存、从详情返回后保留选择和个人位置。
- 详情先读取本地快照，以独立请求核对最新状态。验证打开大流程时分步构建，迟到的详情读取不覆盖新选择，保留正在编辑的草稿、答复和已有审批入口。
- 验证手动刷新、无法延续增量时的完整读取、离线状态、身份切换、首次发现项目工单及长短窗口内同一事件的合并。
