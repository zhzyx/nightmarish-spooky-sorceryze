# E06 将人工修订交给接续任务

在模块侧栏勾选「继续当前工作」并填写须保留的意见。先前发送的脚本选区和场景节点可以在同一会话内保留为目标。工作台在发送前固定选段或对象的起始内容，以实际会话回执确认绑定；重开编辑器后按工程、账号、模块、事项及对话恢复。旧草稿缺少可核实起始内容时返回未知。

显式接续中，文曲重新核对文档权限和最新头版本，按起始与最新版本定位发生变化的段落。普通历史引用仍指创建时的版本，未改变的长段落无需重复发送。脚本只带原选区的文本和摘要；选中节点带已序列化的可读属性和修订。「保留意见」随本轮快照固定。

Mac 实测两个编辑器进程和两个天璇账号。脚本第 3 行从 11 改成 29，节点 x 从 5 改成 37.5，设计文档在原账号草稿固定 v2 后由协作者保存 v3。重开后在同一条模型 HTTP 请求核对三类起始与最新内容、作者、原引用和保留意见。未修改的 4 万字符段落没有占用差异载荷。[设计条款](gonggong-ai-workbench-plan1.md#e06) · [实际下一轮输入](../data-collection/gonggong-ai-workbench-plan1-e06.json)
