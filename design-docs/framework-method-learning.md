# 共工从复盘自主学习并在相似任务中验证复用

用户要求重点沉淀可重复执行的学习方法和学习能力。当前框架按复盘、纠偏、失败、复用结果等真实事件，在任务授权内提炼经验、绑定范围与证据、去重、按相关上下文检索，并登记复用反馈、反例、修订、失效或撤回。沿用元衡的适应与连续性边界、谛听权威记录和原主责；冻结纲领和元衡上游原件保持原指纹。实现可运行入口和测试，使下一张同类工单能找到经验，同时不把局部结论变成全局指令。

关联 [#687](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/687)。首条实证采用前次实际缺陷及验收，覆盖构建边界学习实例；本次引擎交付后补入新的验证证据。验收包含新录入、重复重放、作用域隔离、反证或撤回后检索停用、修订保留原证据。独立交付至 main。
