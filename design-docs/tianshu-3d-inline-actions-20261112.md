## 范围与验收

- 模型关联工单详情在 3D 侧栏打开，复用天枢详情模块及真实工单宿主，展示设计和关联内容。
- 等待回复入口在同一侧栏显示问题及原生工单聊天，用户可输入答复并发送；继续既有会话与权限流程，不另造执行来源。
- 结构化问题支持原有答复宿主；操作确认复用天枢确认模块，只有用户点击才执行。
- 模型、工单、仓库或身份切换后迟到回执不能操作新目标；失败有明确反馈，草稿保留，不重复发送。
- macOS arm64 候选编译，隔离 headless 编辑器通过控件信号验证详情、答复入口、权限及切换失效；保留真实屏幕像素、焦点和其他平台为未覆盖。
