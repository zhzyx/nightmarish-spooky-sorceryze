# 编辑器页面能力自动注册与统一 AI 操作路由

## 用户要求与授权

用户在语义控制与多步骤引导交付后提出两项后续要求：新页面自动加入高亮、自然语言打开、输入等命令能力集合；引擎内外任意已接入 AI 认定用户意图为引擎操作时，自动进入同一流程。用户已确认同时需要本机 Codex/Claude Code 等工具与外部自建 Agent/HTTP 客户端。沿用本聊天的实现、必要验证、提交和交付授权。

## 交付范围

1. 页面和控件能力自动注册。沿用现有核心 ID 与插件注册接口，自动发现编辑器 Dock、TabContainer 页面、编辑器窗口内容，以及其常用按钮/文本/数值输入控件。新页面无需修改中央动作白名单；有稳定名称或布局键时自动 ID 可复用，支持可选语义元数据。注册随 UI 生命周期更新，不把游戏运行场景当编辑器 UI，不向模型发送完整 Control 树。查询和遍历有界，卸载、重建和重排重新解析。
2. 能力由实际控件类型与状态决定。统一提供打开、显示、聚焦、高亮、文本/数值输入及按钮操作；不支持的动作明确拒绝。保留已有引导和设置写入机制，用户可通过模型搜索目录后选择明确目标。
3. 统一消息路由。结构化消息明确 `intent=engine_operation`，携带来源、请求 ID 和声明式操作；引擎内 HTTP/Codex/CodeBuddy 均使用同一宿主路由。只提供自然语言时返回规划所需目录和下一步契约，由当前 AI 规划后再提交，不用关键词猜测直接执行。
4. 本机桥接。编辑器运行时公布本项目私有发现文件，使用随机令牌和回环地址 HTTP；提供能力发现、提交请求与结果查询。外部命令行客户端复用同一协议。非操作消息、未知目标、关闭权限、仅咨询、过期会话、重复请求和繁忙冲突有明确结果。外部操作不能越过编辑器确认或自点确认弹窗。
5. 自动路由约定进入所有内置模型通道的工具说明；外部客户端提供机器可读能力及使用文档。未接入本接口的第三方 AI 不会被凭空拦截或赋权。

## 安全与兼容

不注册秘密输入、显式排除子树或宿主授权控件；不提供任意对象方法调用、脚本执行或坐标点击。修改和点击先预览，确认同时绑定目标对象与原值，替换控件或更改后拒绝旧确认。沿用宿主工具许可、仅咨询与自动执行选择。HTTP 不监听公网，不接受浏览器跨站请求，不把令牌写入日志或 Git。退出停止服务、取消未完成请求并清理本次发现文件。

## 实现与本地验证

`AIChatEditorRegistry` 监听编辑器自身场景树的新增、移除和重命名；查询时有界刷新，自动 ID 基于页面/控件路径，运行期间按 ObjectID 保留重排身份。重复别名拒绝解析。`AIChatEditorControl::route_message` 统一意图、规划、去重和结果状态；原生确认绑定旧值、目标实例及引导版本。外部桥接在独立子节点处理回环 HTTP，不开始或结束聊天/工单轮次。

外部标准库客户端支持按项目发现、多实例选择、能力查询、提交、等待确认和恢复结果；接入方通过能力返回的工具说明选择路由。真实编辑器场景验证了临时标签页和后增输入自动发现，以及当前主线大千 Dock 无适配自动入目录。输入、数值、选项、原生按钮、重复 ID、冲突、拒绝/停止、值漂移、同路径控件替换、重排、秘密输入切换、别名冲突、权限/仅咨询、令牌/会话/浏览器来源、超限后恢复、CLI 与退出未确认不执行均通过。
