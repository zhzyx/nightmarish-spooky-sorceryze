# Godot Engine 内嵌天璇工作台

需求 ID：godot-web-platforms-20261118。路径均以仓库根为基准。

## 用户目标与范围

用户要求将天璇、文曲等 Web 平台整体嵌入引擎；2026-11-18 最新决定为“撤回刚才的指令，仅接入godot engine”，替代此前 Engine Next 与双引擎选择。本任务仅修改 Godot 定制编辑器，不修改 Engine Next。复用 apps/tianxuan 完整网站，覆盖文曲文档、需求、司南工单、多宝、搜索、账号及设置；保留平台实际认证、权限和能力差异。按当前可用 macOS 宿主先验证原生嵌入；Windows 接入按实际 SDK、构建及运行回执验收，平台缺口不能计为通过。
将完整 Web 应用作为宿主窗口内的浏览器视图，允许在场景与工作台之间切换。连接地址由用户显式配置，浏览器使用独立用户配置目录保持登录；不把令牌放在 URL、命令行或公开回执中。复用现有 Web 服务，不在本任务替换生产数据库或部署。Web 页面继续通过自身 HTTP/WebSocket API 工作，不暴露任意本机执行桥。

## 验收

1. Godot 编辑器工作区入口可配置工作台地址并打开窗口内的完整 Web 页面；无需系统浏览器。未配置时提示连接地址，其他工作区正常使用。
2. 页面内文档、需求、工单、多宝、搜索、登录与设置导航沿原站点工作；会话在同一用户配置目录重开后保持，退出登录沿平台逻辑生效。
3. 调整大小、显示缩放、隐藏/恢复及关闭遵循窗口生命周期；异步初始化迟到不会访问已销毁宿主。Web 输入不驱动游戏摄像机或因 Escape 退出整个引擎。
4. 导航仅允许配置的站点来源（HTTPS，或本机 HTTP 开发服务）；拒绝 file/javascript/凭据 URL 及意外站外跳转。下载保留浏览器的用户交互，网页无宿主对象和执行消息接口。
5. 缺 WebView2 runtime、无效地址、加载失败及浏览器进程失败有可见诊断和显式重试/返回场景入口，不自动替换有效安装或无限重启。
6. 构建明确 WebView2 SDK/loader 来源和架构，分发包含实际依赖及摘要。通过受影响构建/测试、独立审查、工单门禁、CI、main 回读。确定性测试、Windows 实测、网页业务及生产服务验收分别记录，未知不计通过。

## 2026-11-18 个人 Key 登录失败接续

用户在入口恢复后反馈个人 Key 被拒绝。当前执行者负责 HTTP 与隐藏原生 WebKit 的技术对照，不要求用户自行切换浏览器验证，也不索取或读取个人 Key。HTTP 合成无效 Key 对照返回 401，服务健康检查正常；该结果不能证明用户 Key 已撤销或过期。成功登录与业务验收仍未完成，#1540、#1454、#1474 均保持开放。服务器账号/Key 状态需沿有权管理通道核查；当前 Mac 未具备该通道，不绕过权限或重置用户凭据。详见同一 server-entry 证据。

隐藏原生 WebKit 调用部署页面的实际登录处理器，合成无效 Key 得到 401 与对应错误文案，进程退出 0。该对照验证请求链路，未验证用户 Key、成功 Cookie 或登录后的业务。测试中误选搜索表单的夹具问题已修正并保留原日志，不作为产品缺陷。测试应用与隔离 profile/cache 已清理。
