# 按宿主配置使用并行容量

需求 `parallel-configured-capacity-20261111` 对应 #777，父目标 #773。用户要求在已连接账号和 CLI 的编辑器内充分使用可用并发能力。

原执行器将容量固定限制为 1..2。现在接受明确授权配置中的正安全整数，消费者数取容量和实际就绪任务数的较小值。任务仍按原入口核对工单、模型能力、工作副本、共享槽位及终态；CLI 成功仅进入待验收。

实际变更是既有 Node 宿主工具 `tools/godot_parallel/runner.mjs`，没有新增模块或原生输入，不需要重编译编辑器。编辑器通过既有 Node 子进程接口调用它。回退为恢复前一 runner；保留所有在途任务及其共享预留，不通过删除占用重新派发。

验收使用临时 Git 工作树与受控 CLI：三个独立进程必须全部到达屏障后才能退出；极大合法配置只启动实际两项任务；非法容量在派发前拒绝。原有去重、依赖证据、来源绑定与失败回执回归同时执行。此证据不代表供应商账号的三路并发能力。
