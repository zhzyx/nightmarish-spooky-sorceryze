## 最新决定

- 规范面向本引擎第一方 C++ 代码，不照搬其他引擎的类型命名体系。
- 新增文件、类和函数采用项目规范；存量代码不做批量迁移。
- 存量文件中的小修不扩大重命名或格式化范围；整体重写的类、函数和文件必须执行新规范。
- 布尔变量沿用 `b` 类型前缀；变量采用“小写类型前缀 + 首字母大写的语义单词”。
- 函数采用无下划线的 PascalCase；C++ 源文件名采用 PascalCase 并减少下划线。
- 参数可使用 `in_`／`out_` 表达方向，输出参数不再使用 `r_`。
- 函数、类型和控制语句的块级大括号另起一行；所有流程控制块必须保留大括号，执行逻辑不得与控制语句写在同一行。
- 本次不调整全局 `.clang-format` 或 `.clang-tidy`，不以自动格式化批量改写存量代码。
