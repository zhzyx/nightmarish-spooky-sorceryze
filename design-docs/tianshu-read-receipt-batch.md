# 天枢连续读取文件

需求 tianshu-read-receipt-batch，关联 #650 和父单 #592。免独立 API 的 Codex 工单读取多个独立文件时，旧版对每个开始与结果各等待一次完整数据集校验。

同一批最多 16 个相邻 read_file 共用开始和结果回执。开始回执通过才允许访问文件，逐帧执行并重新核对权限和候选。每个实际访问仍持久保存开始、结果和原调用标识，可立即展开详情。用户停止时结束已启动的批次；新指示按原队列跳过剩余提案。整批结果回执通过才向模型发送并推进可恢复游标。其他工具和恢复中的命令走原执行路径。

整体验收使用原始随机文件内容和当前聊天输入框追问，另外验证停止、改口和结果回执失败。工单证据见 [实测记录](../data-collection/tianshu-read-receipt-650.json)。
