# 马良随引擎提供 Hunyuan3D 本机图生网格

用户要求适配 Mac，并让 Mac、PC 的马良引擎包含模型，安装后无需配置环境。目标发行环境为 Apple Silicon macOS 和 x86-64 Windows。复用现有 Hunyuan3D-2mini 图生未贴图网格工作流；输入已有图片时应可完全离线生成。

发行包内须实际包含版本固定、校验通过的模型、该平台可迁移的 Python、推理依赖、ComfyUI 及第三方许可证。首次使用直接从引擎的相对位置发现它们，不要求安装包管理器、输入本机路径或另启服务。服务状态、中间图片、日志和输出使用可写的本机目录。用户已选择的其他生成方式继续可用。

验收使用干净的用户配置和移动后的发行目录。从马良输入一张图片，运行网格节点、预览、保存并重新打开非空网格。每个平台分别记录机器、模型摘要、执行设备和实际结果。区分开发机已有运行库的历史验证与本次自包含发行包验收。

发行构建和 Windows 原生验收由子工单 [#616](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/616) 承担。编辑器与发行资源在同一候选中集成，Windows 检查从该候选编译编辑器，再用同一版脚本组装和验证。两项分别记录验收结果。Mac 编辑器从已含模型的发行包自更新时携带同一套资源。
