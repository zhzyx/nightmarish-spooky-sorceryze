# 当前 Windows 编辑器链路清查

父工单 #748。审查对象为桌面「共工编辑器」启动的工作台，覆盖旧数据工作树、已有对话和新启动的编辑器。用户报告的并行入口是天枢 Issue 内的聊天指令派发。

| 链路 | 对照与发现 | 验收或跟踪 |
| --- | --- | --- |
| 桌面、启动器、安装清单 | 读取快捷方式、项目参数、运行 EXE 与主线清单；安装代码、所选数据工作树和新建的执行候选可以是三个目录。 | #722、#747；每次部署回读进程、工程和文件摘要。 |
| 天枢导航、看板身份、详情、模型与开工 | 工单读取、范围切换、六个 GongGong 面板操作、权限拒绝、卡片和原生 Enter。Windows venv 的临时重定向进程会让相同编辑器丢失会话身份。 | #749、PR #765；非 venv 和 venv 路径分别验证。旧看板的历史实现保留原数据工作区语义。 |
