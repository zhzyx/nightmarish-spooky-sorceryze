## 用户需求与范围

处理遗留内容、同步 Git、测试引擎接入、提交可运行引擎代码，使 Godot AI 聊天调用当前 Olympus。工单以 Issue 体现，类别以标签体现；需求存放 design-docs，谛听交接存放 data-collection，真实事件存放 olympus-hermes-data。

最新明确范围：交付 Olympus 与 Godot，不提交整套 Gonggong；本机来源位置改为有明确基准的相对路径。共工原审查文件保留在真实上游，本仓库记录完整原始文件摘要，不改写原批准、不携带整包 ZIP。历史外部参考标识不是运行依赖。Godot 官方文档中用于解释 API 的通用绝对路径示例保持原语义，不属于本机绑定。

## 实现

保留 Godot 原有编译目录。原生面板和聊天控制在 editor/docks；唯一 Python 宿主实现位于 customizations/components/godot-host；tools 提供稳定入口、构建和启动脚本；samples/olympus-workbench 是运行示例；tests/editor 保存实际编辑器接入测试。移除重复补丁安装器和 174 个已被标准规则忽略的生成文件，构建时重新生成。

所有模型请求和工具继续轮先调用当前工作区 Olympus 的 agent-context；HTTP 与 CLI 均注入经过校验的上下文。准入失败、缺少依赖或前置文件回执失败时拒绝发送。停止先取消执行；迟到结果不恢复旧请求。重启恢复重验框架和绑定，拒绝时保留日志，恢复期间锁定会话、后端和快照切换。

运行前绑定实际 Agent 定义快照、租户、需求、来源、授权、outbox 和数据源。事件先持久排队，回执后删除队列文件；下一轮检查重试未送达事件。记录消息/步骤元数据、结束及覆盖说明，不采集正文、密钥、模型内部推理或未测得的 token。

Olympus 已按共工 0.9.0 当前主线准备完整候选，Ariadne 升到事件驱动 0.4.0，不引入旧定时调度。prepare 和候选验证不解锁生产；正式 build/check/上下文入口保持严格。赫尔墨斯豁免模块与生产数据不受同步覆盖。
