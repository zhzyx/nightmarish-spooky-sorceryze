# 马良编辑界面以右键菜单为主要操作入口

<!-- gonggong-request:maliang-context-menu-first-20261107 -->

## 用户目标与最新决定

用户原话（2026-11-07 当前 Codex 聊天）：“新issue，让编辑界面大量基于右键来处理，而不是上方的工作功能按钮”。按当前讨论范围，指马良节点/工作流编辑界面。用户随后明确授权：“直接把 #411 落地吧，做好后更新到我现在用的马良编辑器。”本次执行覆盖实现、后台验证、独立审查、既有 PR/CI/main 交付以及当前本机马良安装更新。

现状：节点编辑需要反复移向顶部或旁侧成排功能按钮；操作与当前对象脱节，占用画布空间。目标是在操作对象附近完成工作，显著精简上方功能按钮。

## 交互要求

1. **空白画布右键**：创建节点按类型分组，可搜索常用生成类型；新节点出现在右键位置。工作流级操作放入清楚的分组。
2. **节点右键**：提供针对该节点的运行并预览、查看已有结果/本次会话历史、编辑提示词及参数、重试、复制和删除等常用操作。右键对象决定操作目标，避免误操作上一个选中节点。菜单按节点状态显示可用项，不能执行的操作说明原因。
3. **连接线与多选**：连接线支持右键断开；多选时按选中集合提供适用的复制、删除等操作；不适用的批量动作不伪装为可执行。右键已在多选内的对象不应无故清空多选。
4. **顶部精简**：将与节点/连线/画布对象相关的编辑动作迁入上下文菜单，收起重复、低频功能按钮。顶部仅保留少量确有全局意义的入口、必要状态和运行控制；具体保留清单需在实现说明中列明，避免只增加右键菜单而保留原有整排按钮。
5. **保留详细编辑与可发现性**：右侧属性与预览区用于详细编辑；现有快捷键和必要替代入口保持可用。菜单用中文、清楚分组，快捷键可见，避免过深层级。支持 macOS 鼠标右键、触控板双指点按及 Control 单击。
6. **主动执行语义不变**：弹出菜单本身不触发生成；用户选择运行项后才执行必要上游和目标节点。沿用已有取消、重复触发防护、历史结果及发布确认行为。

## 验收标准

- 可仅通过右键完成创建节点、编辑节点、运行并预览、查看结果、重试和删除的主要流程，不依赖顶部编辑按钮。
- 空白、节点、连线、多选四类上下文对应正确菜单；操作目标、节点创建位置及多选集合均正确。
- 顶部对象编辑按钮明显减少，并列出迁移前后入口；常见窗口尺寸下画布空间得到释放，菜单不超出可见窗口。
- 在运行中、成功、失败、取消、缺少输入等状态下，菜单可用性与实际执行一致，不重复提交，不误用旧结果。
- 保存与重开工作流、图片与网格预览、历史切换及原发布流程回归通过。
- 使用 macOS 隔离工程和控件信号后台验证上述链路，保留必要的交互可发现性检查。
