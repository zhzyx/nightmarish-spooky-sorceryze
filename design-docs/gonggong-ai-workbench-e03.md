# E03 识别已保存的脚本修订

模块对话从编辑器实际发送的脚本选区登记起始位置和摘要。原生保存信号记录当前账号和保存字节的摘要，下一轮按同一工程、账号、模块、事项和会话回读磁盘。仅光标变化时保持原版。外部程序写入时记录磁盘来源，操作者留空。下一轮可以核对脚本路径、原选段范围、新旧摘要及该范围的新正文。收到目标会话的回执后才推进修订，切换任务选区会替换观察目标。

Mac 原生验收通过编辑器保存脚本第 3 行，再由外部写入同一文件。模型 HTTP 传输替身在相应轮次读到 29 和 53；只移动光标的轮次没有新修订。[设计条款](gonggong-ai-workbench-plan1.md#e03) · [验收证据](../data-collection/gonggong-ai-workbench-plan1-e03.json)
