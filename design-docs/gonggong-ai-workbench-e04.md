# E04 识别场景或资源的人工保存

工作台将原生选择的节点或资源映射到对应序列化文件。保存后在当前模块草稿记下目标摘要和登录操作者，重开后可按持久化的会话绑定恢复。继续任务时核对当前文件字节，并从资源依赖列表逐个读取工程内的依赖摘要。缺失、不可读或通过符号链接指向工程外的依赖没有已知修订。
