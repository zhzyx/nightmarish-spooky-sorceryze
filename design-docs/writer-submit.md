# 所有仓库写入者使用同一签发和自动提交入口

[工单 #134](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/134)

承接 #131。用户要求所有在共工仓库有提交权限的协作者都可快速签发并自动提交，包括当前操作者及其他安装。已合入的本人 PR 路径解决了交付身份，但仍需手工提交，原自动通道还需要私有宿主密钥及预制 grant。

交付一个仓库内的 Git 入口，以当前 GitHub 账号和绑定仓库核验写权限，针对已暂存的工单候选运行正式门禁、自动创建提交并核验、签发精确候选和提交 PR。正常合入遵循原 PR、精确 CI、独立审查和分支规则。签发限本次 Git 交付。验证本人实走及跨身份正反例和重试边界。责任人为本工单的独立工作树操作者。
