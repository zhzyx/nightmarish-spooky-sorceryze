## 目标与已确认范围

面向当前工作区引擎开发，后续扩展游戏开发与企业。Windows Godot 内嵌现有 Web，复用已有私有化服务器。首页以 AI 对话、关键待办和运行任务为中心，详情随上下文展开。Apple 官网风格，品牌扁平化，主题跟随系统并可手动切换。

沿用偃师方向、策划与详细设计版本确认流程。文档优先 AI 结构化读取和局部修改，支持多人实时编辑、版本比较与恢复。工单支持父子单、依赖、迭代、里程碑、路线图、工时、自定义字段与状态，覆盖非代码及美术 3D 管线。概念图和模型由用户确认，确认绑定资产修订；复用已有制作能力。

多宝原生管理文档、代码、资产及变更。完整迁移当前工作区关联代码历史、需求文档、Issue、PR、评论及附件，保留来源与关联。新任务按项目或需求选择入口，暂不全部切入天璇，也不做双向同步。未结 Godot 工单仅迁移与记录，不执行其实际内容或落地，不修改其业务验收与关闭状态。

使用已有个人 Key 身份并提供管理员创建、查看、撤销入口。复用现有身份基础，本期权限产品范围限于上述入口。

平台长期运行 Agent，允许外部 Agent 接入。批准后自动推进执行、验证、审查、交付及进度回写。服务器协调多个节点，Windows 本机与服务器均可执行匹配任务，关闭 Godot 后持续运行。节点使用各自配置的 CLI 身份，匹配工具和运行环境，未知执行先对账。接入本机已有 CLI 与模型目录，支持司南选模及用户指定切换。

容量设计为 50 用户、每人 5 个并行 Agent，当前使用实际并行规模验证。记录真实上下文读取、模型调用、等待、返工与人工操作，效率结论限定实测环境。
