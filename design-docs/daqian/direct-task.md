# 大千确认建单与共工需求判断

Godot 大千只提供一个确认入口。用户确认后，宿主先用原始正文、稳定草稿标识和当前账号在仓库查重、创建并回读 planned 工单。重试使用同一标识；可在需求窗口指定模型，建单本身不使用模型。真实 request.created 由谛听记录并交给司南。

建单后的只读判断采用当前框架和工单原文。司南判定目标、范围与验收是否存在需要偃师处理的问题；内容充分时直接进入运行准备，需要设计或澄清时才调用偃师。补充答复、判断、范围及验收都关联同一工单和来源版本。缺少模型或判断失败时保留已创建工单，恢复后继续判断。仅在满足条件且用户点“开始推进”后通过 issue-start 和实际执行准入。流程图按真实回执添加或更新相应节点。

工单与授权来源 https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/174 。路径相对仓库根。保留历史分析会话的工单关联和在途回执。
