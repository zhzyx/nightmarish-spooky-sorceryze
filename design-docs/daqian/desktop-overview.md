# 大千桌面总览与键盘交互

延续 #222。用户要求继续优化大千的交互设计和界面效果，以 macOS 桌面应用的列表浏览、键盘操作和选中反馈为参照。交付范围为 Godot 大千子模块。总览提供紧凑列表和依赖图切换，搜索与筛选在两种视图中一致；列表支持键盘打开工单并返回原选择。视图偏好随当前仓库与用户保存。使用 Windows Godot 原生编辑器的隔离 headless 场景验证控件、布局与操作，不操作用户桌面。停止条件为原生回归、正式门禁、CI、main 回读及工单收尾。

关联工单 https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/297 。

补充验收：允许调整大千窗体和画板节点大小，窄幅时控件重排。缩小单条工单进入个人工单图，继续缩小进入当前项目开放工单图，最外层继续接受缩小。项目层按当前仓库分页读取开放 Issue，排除 PR。向内可返回到单条工单，限制细节最大倍率。全部缩放和拖动走后台原生控件用例。

个人层展示本人创建、被指派和主动跟进的工单，保留关联依赖和已关闭记录；项目层按仓库分页读取当前开放工单。从 32% 向外跨层，项目低于 4.5% 后以项目标记显示远景，继续缩小累计逻辑层数；向内可返回，单条工单细节上限为 160%。已有手动卡片布局的账号默认进入图，其余默认列表，之后记住用户选择。
