# 大千模型自动接入与工单图可读性

当前聊天连续要求修复一键识别导入本地 AI 仍需手工续接，并修复总图文本越界、各图的 Issue 编号与富文本链接以及单工单状态 brief。范围为 Godot 大千及其宿主适配器。按两组验收：已有可用本地配置自动识别、登记与文本能力验证，真实失败给出原因，重复接入不重写凭据；总图与单条工单图提供可打开的可信 Issue 链接，长标题及状态不越界，单条页常驻当前状态、等待或阻塞原因。保留明确手工覆盖、权限与真实证据边界。后台验证，不操作用户当前编辑器。完成条件为本地回归、正式门禁、CI、main 回读及工单收尾。

项目全部工单按负责人分区，多人共同指派时在各负责人区域均可找到，未指派单独展示。光标在区域上放大进入该负责人的列表。个人工单和负责人列表按待决策优先、状态、工单类别及编号稳定排列。
