# 大千 · 跨模型 Agent 并发和结果汇合

需求 ID 为 daqian-parallel-20261105。父级需求为 daqian-workflow-20261105，条款见 [完整设计](../daqian-workflow.md) 的「模型与执行」。相对路径以本文目录为基准。当前聊天负责本次实现与证据，交付目标为仓库 main。

## 范围

隔离各 Agent 的请求、上下文、取消和实际结果；按当前授权、依赖、容量和资源冲突派发，等待/取消只影响相关分支。

## 验收

两端从同一个编辑器派发两个 Agent，跨供应商真实请求区间重叠；正常汇合取对结果，独立取消或待答不妨碍另一分支，未知回执先对账。

前置依赖为图编排与模型接入。原生父子工单关系、候选与接收回执由父级档案统一追溯。

父工单 https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/119

## 跨工单验收

同一个 Godot 大千面板由一个事件驱动的司南调试宿主接收多个 Issue 的图，每次启动为工单与节点组合分配独立运行身份。所有图共用两个调试执行槽；关闭一个工单先停止其工作者，等待实际终态后释放容量。即使两个工单使用相同节点名，也分别归档工作者、模型、输入和结果。个人调试记录可在停止和切换工单后查看；这些记录与生产回执区分。原生用例覆盖跨工单请求重叠、停止第一单后第二单继续，以及返回第二单查看它自己的结果。
