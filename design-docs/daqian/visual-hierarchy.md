# 天枢工单的视觉层级

延续 #297。用户强调视觉效果并要求继续优化。本次在 Godot 天枢内优化工单总览和依赖图的标题、状态、主要操作和窄幅排布。用同一组工单在独立后台渲染环境对比实际界面，验证长标题、待处理状态和选中反馈，复验键盘、缩放及边缘调整。停止条件为本地验证、门禁、CI、main 回读和工单收尾。

关联工单 https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/333 。

实际画面对比使用独立 Windows 桌面与隔离编辑器配置，读取 Godot 视口像素。复核深色、浅色的 1222×709 总览和依赖图，以及 612×709 窄幅。使用固定的 10 张示例工单；旧版把第二个标签挤入滚动箭头，新版两个入口同时可见。列表按空间增减负责人列，选中行与待办独立标示；依赖图以标题打开工单，并在两行内显示长标题。原生窗口进度对话框在隔离桌面不获取活动窗口，主视口的截图正常。未进行 macOS 真机验收。
