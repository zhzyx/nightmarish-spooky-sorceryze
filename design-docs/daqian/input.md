需求 ID 为 daqian-input-20261105。父级需求为 daqian-workflow-20261105，条款见 [完整设计](../daqian-workflow.md) 的「图片输入」。相对路径以本文目录为基准。当前聊天负责本次实现与证据，交付目标为仓库 main。

## 范围

需求卡分别支持推演与创建并执行。图片为独立节点，可选文件、拖入、粘贴、预览和添加说明。按问题类型创建待答节点，连到对应任务；离线草稿在回读后提交。

## 验收

两端各验三种图片入口、单图片扇出、自动与手动关联、结构化答复、只续跑对应分支。复用已有真实需求时不重复建单。

前置依赖为图编排与画布。原生父子工单关系、候选与接收回执由父级档案统一追溯。

父工单 https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/119

## 当前来源与答复处理

偃师文档的「待确认」条款按适用内容投影为输入节点：普通问题输入文本，明确的截图请求或【图片】条款生成图片节点，【选择】问题 | 选项A | 选项B 显示选项，【确认】绑定当前问题内容及版本。答复记录操作者、节点、问题版本及来源修订，在源事务中回读。重复提交同一答复可恢复；不同答复或问题已变更时保留草稿。用户表达同意的记录只代表该项答复，不授予 GitHub 权限或替代独立批准。status:needs-decision 可先提交必要答复；生产派发仍按原门禁。

当前画板使用流程提供的图片节点及其任务关系。已有图片节点支持选择文件、粘贴截图、预览和填写说明。待答图片通过输入节点提交，临时内容随个人草稿保存。调试答复只唤醒相应依赖分支。画板交互的变更见[工单 #647 的设计](../tianshu-disable-manual-graph.md)。
