# 天枢工单详情的操作与恢复

父项 #442 的第二和第四阶段要求建单、判断、澄清、开工和继续对话在同一工单完成。当前 workspace.gd 的按钮文案、可用状态和点击后的分流分别读取本地关联、路由判断、开工回执和运行标记。检查各处规则一致性，拆出权威回执到用户动作的独立逻辑，将状态显示和实际执行绑定到同一份判定。保持原宿主准入、模型配置入口和当前账号、草稿、工单隔离。
