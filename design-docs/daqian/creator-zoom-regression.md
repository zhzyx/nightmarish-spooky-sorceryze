# 天枢在 macOS 上按创建人缩放

#427 的来源为 macOS arm64 编辑器在 55 单图中的间歇超时。父项 #442 的 Windows 回归已经三次通过同一图场景，主线 #444 已使缺失创建人区域的测试立即输出筛选和活动标签并失败退出。

现有 macOS 构建先产出 arm64 编辑器，再打包两种架构。用已编译的同一 arm64 编辑器，在独立临时项目及编辑器配置下连续运行原 graph 场景三次。每次记录候选二进制 SHA256 和结果；出现失败按首个现场继续排查。静默场景检查进入 writer 和未知创建人区域的真实滚轮、选中及筛选，使用生产控件。验收以实际 macOS 回执为准。
