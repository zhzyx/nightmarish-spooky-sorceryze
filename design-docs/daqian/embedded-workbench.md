# 在大千内配置模型并完成工单工作

需求 ID 为 daqian-embedded-workbench-20261107。用户在 Codex 要求，大千可执行的工作均应在大千完成，包括未预选模型时的需求判断、开工、关联对话与继续执行。现场为 #195；此前 #210 节点确认与 Markdown 侧栏继续适用。

## 工作流程

从大千自身进入工作连接、后端及模型配置、模型刷新和手动选择，沿用已有 API 与本机 CLI 的真实配置及权限；模型设置和推进对话在大千内可用。恢复已有工单绑定，保留草稿、模型选择、工具确认和会话上下文。缺配置时能在当前位置处理，完成后回到原工单继续。常规 AI Chat 入口可独立使用。

## 验收

在 macOS 原生 Godot 中，从无预选模型和已保存的工单分别验证选择、需求判断、开工、阅读结果、继续对话和返回图；核对工单/账号与审批隔离。复用已有后端，不引入第二套模型执行器。文件路径以仓库根为准。
