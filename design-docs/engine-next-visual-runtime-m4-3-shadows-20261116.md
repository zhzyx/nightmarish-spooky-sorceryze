# M4.3 方向光阴影分片

沿用 #1343 与父单 #1323。HDR/相机基础 PR #1347 已合入 main dcb0c05710a4b9401a8183389ce072d185db4c3d，本分片已同步该主线。

## 当前交付范围

- RenderConfiguration 增加可选方向光与阴影字段，旧配置读取保持兼容。
- 四级有限 Reverse-Z CSM，稳定中心 texel 对齐、保守视锥与场景投影范围。
- 每帧独立 D32 四层深度数组，显式 FrameGraph 写入、采样与末态恢复。
- OPAQUE/MASK、镜像与双面深度绘制，3×3 PCF 和级联过渡采样。
- 运行时阴影开关、分辨率、距离和偏差参数，保留源包身份。

局部光阴影、PCSS、虚拟页缓存、时域处理、SSR 与体积透明继续在 #1343 后续分片实现。

## 验收

CPU 数学与边界测试、四个级联视锥覆盖、静态微移稳定、屏幕外 caster、MASK 与负缩放验证。真实 GPU 对照开启/关闭阴影、移动光源、配置更新与回退，检查阴影资源与深度调用、GPU Validation、M2 父变换网络场景和跨平台 CI。结果绑定实际二进制与来源。不得用基础编译通过声称已完成本分片视觉验收。
