# E09 保存二进制或不可合并资产候选

在工单详情选择「另存所选版本」，或在并排比较窗选择「另存完整原件」。编辑器从工单读取对应版本并核对 SHA-256。写入使用文件系统的独占发布操作。如果目标已有不同内容，编辑器保留原路径下的文件，把收到的字节另存为同目录下带摘要的候选文件。下载期间发生的保存同样受保护。重复下载会复用字节一致的候选，曾被编辑的同名候选也会保留。

对照窗显示本机原件和工单候选的路径、摘要与预览。PNG 显示图像，自包含的标准 GLB 显示网格，其他文件显示字节信息。点击「选用本机原件」或「选用工单候选」时重新核对两侧摘要，并记录选中的路径和修订。工单详情中的「比较本机资产候选」可重开记录。选用记录位于当前 Godot 项目的编辑器元数据，按服务、账号、项目和工单划分。原件与候选始终保留在所选目录。

两个编辑器保存入口复用现有工作台、天璇工单版本接口和多宝内容读取。新增控件与已有工单控件一起由 SCons 嵌入原生编辑器。Windows 使用不替换目标的移动操作，Unix 使用同文件系统的独占硬链接。回退到此前的编辑器即可恢复旧入口，已另存的文件可独立打开。Windows 实测使用独立 headless 编辑器、真实本地天璇服务和多宝数据库，覆盖原件在下载期间变化、模型候选重名、两侧预览和选用后重开。
