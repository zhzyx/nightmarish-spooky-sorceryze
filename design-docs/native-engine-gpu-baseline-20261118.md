1. 核实当前 Windows CPU/GPU/内存/驱动，使用实际 GPU 显存查询，不能把 WMI 32 位 AdapterRAM 当作准确显存。记录实际测量来源、时间与限制，不当作最低配置。
2. 从当前主线按既有 BuildVisualRuntime/资产工具构建，记录原生输入、二进制、shader、工具链与生成资产摘要，或复用可逐字节验证的已接受产物。全部生成物位于本任务明确目录，不替换安装。
3. 隐藏窗口运行真实 D3D12，不使用 dummy/headless renderer。固定种子、分辨率、镜头、帧数、配置，记录暖机策略、CPU/GPU 原始帧时间、P50/P95/P99、显存/内存可取得的实际值、验证错误和实际进程终态。缺指标保持未知，不估计。初始取当前屏幕量级与 4K 离屏目标，不能将隐藏目标当作物理 4K 输出。
4. 同一二进制/场景/配置下，串行测量空闲与本机真实原生工作者负载；后台负载须明确实际工作、并发、资源和完成回执，不把人工 sleep 称为 AI 推理。记录前台帧时间变化、后台吞吐、真实 CPU/IO 条件，保留离群/失败，不择优删样本。负载只用确定性本地工具，不调用模型或占用他人工作者。
5. 本次程序化功能/性能基线不能代替写实成品场景、画面审美、角色/动画/音频/加载、长稳或 AA 整体验收。#1472 已交付环境重要性采样改进，本次使用其已接受源码，不将此前离散亮点记录直接当作新候选缺陷；#1343/#1323 的其余范围仍按原责任者实际回执验收。测得数据后提出可验证的后续场景与硬件目标，阈值决定仍交用户；不先作保证。

验收：真实源与产物绑定、隐藏 GPU 帧回执、空闲/后台负载可比性、限制与原始数据、独立复核、正式门禁和 main 留底。只交付测量工具/本次证据，不切换生产。必要临时场景/二进制/日志保留至复核及父项比较结束，实际子进程关闭后才处理本任务临时文件；不清理他人资源。

## 首轮实际结果与明确限制

固定来源 fd7281e6266d3e36b9b3cbfaa728daa8edee9db1，保留刚交付的 #1472 环境重要性采样改进。现有渲染构建通过351项测试/454018次检查；原生279项实际输入逐文件回读相同。现有运行时构建及双客户端重连握手通过。未修改渲染器、shader或原生输入。

当前测量主机RTX5080，驱动610.88，实际查询显存16303MiB；CPU Ultra9 285K/24逻辑处理器，系统可见约64GB内存。固定现有自有材质场景15462三角形、10个实例、11材质，使用TAA/Bloom/SSR/阴影/清漆/各向异性与透明面板，未启用体积雾/粒子。两种隐藏目标2560×1440与3840×2160各16帧GPU Validation零错误，随后正常性能设置各进行1200帧的负载前/负载中/负载后试验，保留全量样本，仅统计时剔除前100帧暖机。

四个独立fixture协调器各运行250次真实本地文本producer和检查，共1000次生产、144次发布；每个协调器每次仅一个producer，不是1000并发模型。每个GPU负载测量区间都与四个协调器的真实生产区间交叠。fixture授权/审查回调仅用于加载工作负载，不作为生产权限或语义审查证据。

无额外本任务负载时，GPU graphics P99分别为15.887648ms/29.15488ms；有额外负载时为15.63312ms/28.973888ms；负载结束后为15.778176ms/28.854464ms。仅一次前/中/后episode，不能称为负载使性能改善、统计显著无影响或普遍容量结论。系统中其他用户/Agent进程未终止，全机CPU利用率/I/O带宽未持续采样，无法隔离其全部影响。原始帧时间、实际执行区间、程序和配置摘要在本项JSON中；完整原件按明确路径和摘要保留。
