# R06 多宝写入回执对账

编辑器在物化工程重新提交原选择时，用模块、基线、所选路径摘要和说明重建原调用键。天璇按认证身份查询原生批次。已接收时读取该批次的修订，确认从未接收时才重新发送相同操作。客户端核对批次操作摘要、修订父项、依赖与对象后推进本地工程游标。查询失败时保留原游标。
