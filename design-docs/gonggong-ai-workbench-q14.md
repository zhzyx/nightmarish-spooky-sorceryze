# Q14 验证同一 Mac 文档窗口的人工初稿、局部续写及段落差异

在同一个已登录的原生编辑器窗口新建设计，保存人工初稿，选中第二段并接受模型建议，再由作者修改第三段。版本历史逐次定位第二段和第三段，天璇持久层独立回读三版正文及作者。验收使用可重复的模型 HTTP 响应，提取选区、生成建议、保存和差异查询均走实际服务。运行 tests/editor/run_workbench_document_continuation.py，传入 --godot 和 --report。
