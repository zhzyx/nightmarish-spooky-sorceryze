# 并行工单复用编辑器二进制、可回退业务包与新增模块接入

落实用户要求的完整方案。不同 Git 工单保留精确来源、权限、测试回执和签发，按引擎构建输入和工具链安全复用不可变产物。天枢图布局及展示资源独立打包并验证兼容、加载、回退；评估库存马良和其他嵌入资源的边界。后续新增模块在设计、实现与 CI 中执行同类判断。验收包括两份独立工作树同一输入仅一次实际引擎编译、相同 EXE 摘要与独立业务回执；资源变更同 EXE 行为改变及旧版恢复；原生、生成器、编译环境改变不能误复用；失败、并发与完整性回归。交付包括各子项及整个方案在 main 的实测。

## 本次发现及交付映射

旧入口将天枢图布局和展示脚本嵌入 daqian_scripts.gen.h，马良部分 GDScript/Python 经 bundle.gen.h 进入原生编译。跨工单的完整来源摘要与构建身份混用时，纯业务内容也会重复链接；Windows GUI 与 console 配套、工具链以及版本信息也是实际交付输入。按扩展名或仅按 Git head 推断会同时产生漏重建和多重建。复用引擎只复用编译产物，每张工单在其业务包、工单授权、测试输入和隔离目录上单独记录验收。

三份子候选分别验收。交付时组合验证同一树：编辑器、外置包及其构建/分发入口必须一起到达，旧宿主或仅有 EXE 的安装不能拿新包验收；这部分以父工单作为组合 PR 的唯一签发关联。现有马良包还包含生成服务的 Python 执行入口，仍按实际生成依赖判断；本次优先独立天枢图布局与展示脚本。移动端等无同一安装文件加载约定的目标保留既有路径及相应编译依赖。
