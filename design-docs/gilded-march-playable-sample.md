# 金岬荒境可玩示例

将原创 Gilded March 地形演示作为 `samples/gilded-march` 示例交付。收录 March 场景、16 个 Terrain3D 区域、可玩脚本、布局与观景点、素材许可及 Windows 启动入口。

- 使用支持原生 Terrain3D 的同版本编辑器从新缓存导入工程，核对场景、16 个地形区域和资源加载。
- 按示例说明启动，使用 Tab 切换步行、WASD 移动、数字键 1 至 4 切换观景点。检查导入与运行日志、资源许可与设计来源。
- 在 Windows Forward+ 支持的 GPU 上回读默认 Auto 的实际超分算法及回退。基础运行依赖原生地形，Auto 集成验证依赖 Windows 超分辨率。
