# 大千展示真实待办与后续工作

来源为用户在 Codex 中要求修复大千排查中发现的全部问题。#83 是复现样本，CodeBuddy 功能开发归原单。按用户要求，将范围内已复现缺陷直接修复的协作约定写入仓库入口。

## 范围

- 在流程图保留工单的范围与验收条目，包括合并章节。
- 仅以未答的具体问题和真实待审批操作计入用户待办。在对应节点展示问题、输入及已提交答复。
- 只有标签时说明下一步由工单处理者承担，已有答复后展示真实进度，杜绝标题兜底问题和重复等待。

## 验收条件

- 用 #83 的六条条目验证后续内容可见、用户问题为零，旧标题答复不能成为开发授权。
- 验证真实问题的输入、回执、刷新及待办统计；保留工单状态与执行权限边界。目标为当前 macOS 大千工作台。
