# R01 本机任务检查点

认证客户端用 `POST /api/v1/native/workflow/checkpoint` 和任务 `key` 读取天璇域数据库中的最后一次完整提交。任务、阶段结果、审查意图和编辑来源在同一个事务内读取，并沿用历史任务的工单和文档读取权限。返回目标、固定授权、已完成步骤、输入及产物修订、工作者与已记录的模型调用，以及待判断事项的种类和任务指针。读取检查点不会触发任务执行。

服务在原工作者退出后关闭数据库连接。三个新进程分别读取完整 WAL 副本、最后一个提交帧少一个字节的副本，以及关闭连接后的原库。截断副本保留上一完整提交的产物和待阶段验证指针，其余两者读到已完成的阶段验证。候选用到的服务和测试文件摘要、运行命令及各进程回执见[实测记录](../data-collection/gonggong-ai-workbench-plan1-r01.json)。[原工单](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/1836)
