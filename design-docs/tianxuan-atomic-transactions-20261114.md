## 问题与行为

同一服务实例两个调用持有文档版本 1，原实现先读版本再无条件写入，两个调用均成功生成版本 2，造成修改覆盖及重复历史。修订在 SQL 中使用文档 ID 与预期版本条件，零影响行数返回 VersionConflict；HTTP 对应 409。

实例级可重入锁覆盖完整公开数据库操作、返回数据构造和提交/回滚。嵌套调用共享最外层事务；全部 36 个公开数据库或复合入口使用同一边界，内部成功不提前提交，向外传播的异常回滚整个操作。纯转发入口通过受保护方法访问数据库，初始化迁移仍在实例发布之前完成。独立只读调用不强制开启写事务。
