# M4.3 局部光照验收缺陷

本单关联 #1343 与父单 #1323，处理局部阴影候选的实际验收失败。

## 已复现现象

候选本机二进制 SHA-256 为 b25dd9c3c048694f6f6c5419dc6c547e43d615d21d5822aeef4260b39bc93f2e。点光位置 [2.4, 2.4, 0]、顶视相机、256 阴影分辨率、PCSS 光源半径 3 米时，画面出现与立方体面边界重合的明暗接缝。GPU Validation 为零错误。原实现把跨出当前面的过滤样本限制在本面边缘，缺少相邻面的投影和深度转换。

聚光使用弦长平方上的 smoothstep 软边，但光强换算按均匀外锥立体角归一化。独立积分确认实际有效立体角应为 π(q内 + q外)/2，原实现为 πq外。内角为零时，实际光通量只有配置值的一半。

## 修复与验收

- 点光过滤跨面采样使用相邻面的实际深度，并统一到可比较的光源距离。覆盖六面、边缘、角点、PCF 与 PCSS。
- 聚光按实际角度衰减积分换算光强，覆盖窄角与极限角度，保留无效输入的错误行为。
- 添加能复现两项缺陷的正式回归测试。
- 新二进制重跑原压力场景、正常场景、GPU Validation 与 RenderDoc 捕获，核对原明暗接缝消失和配置光通量的数值一致性。
- 局部光照完整候选通过后按 #1343 的分片交付流程合入 main，回读再关闭本缺陷。
