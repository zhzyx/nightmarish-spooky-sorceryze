# Godot / Olympus 模拟模型流程验收

需求标识：`godot-simulated-flow-20261102`。任务类别：`type:test`。

工单：[GitHub Issue #4](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/4)。

用户最初要求真实模型服务验收，确认未配置服务与凭据后，将范围明确调整为“仅虚假调试即可”“重点是跑通流程然后提交”。本次使用模拟模型服务验证流程，不调用实际供应商，不把模拟回包、用量或临时事件写成生产事实。

验收使用已安装的定制 Godot、工作区运行时与现有 Olympus。重点检查正式准入、编辑器发现工作区、模型请求与回复、工具回合、拒绝时零模型请求、取消、恢复，以及文件回执和持久队列。`admitted` 场景使用真实已批准定义与实际上游，模型端点仍为本机 HTTP 夹具；其余正向传输场景保留隔离上下文夹具，以覆盖延迟取消和恢复行为。

统一入口：`project/runtime/python/python.exe tools/verify_olympus_flow.py --out <验收报告路径>`。执行 16 项桥接单测、4 项分发测试、12 项原生测试（107 断言）、安装路径探测及 8 种原生聊天场景。测试中的框架副本、项目、编辑器设置、回执和模型对话位于临时目录，验收前后比较真实数据目录摘要，必须保持不变。

真实工作区只记录本次用户需求、实际测试结果、审查与 Git 发布事件；用量未知保留 null。报告标明 `external_model_service_tested:false`。通过后将统一验收入口、需求文档、报告和真实文件事件同步 Git。实际供应商服务不属于本次修订后的验收范围。
