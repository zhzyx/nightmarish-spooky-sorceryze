# 多宝原生认证 API 与无 Git 服务入口

需求 ID：duobao-native-api-20261117。父目标 #1382 的 P0-D 接线切片，依赖已验收 #1386 原生候选存储。用户已授权执行；保留现有天璇、司南、合契、阎罗和谛听职责。本项不把候选接收当作独立验收或线上发布。

把 NativeStore 接到现有天璇 HTTP 应用：提交原子变更批次、读取模块头与精确修订/对象、创建与回读精确组合。接口从有效登录会话或已核验生产访问身份派生 actor 和组织，不接受请求体或查询指定 actor/tenant，不沿用不可信 X-Actor 兼容入口。跨组织不可读取其他组织的内容，即使知道其摘要。

原生服务模式可显式启动而不创建 GitService、MergeQueue 或后台 Git 工作者；现有模式保持可回退，生产安装不在本项直接切换。当前服务器的严格访问控制不能被原生模式隐式关闭。使用既有注册/登录能力的隔离实例验证独立组织；多组织生产部署与已有静态租户准入的迁移另行验收。

请求需限制批次、对象数量和请求/解码内容大小，拒绝非法 Base64、未知字段及无效参数；数据库占用明确返回可重试状态，错误响应不泄露本机路径。稳定请求键在真实身份下幂等，冲突返回明确 409。读取清单和内容不能把未知输入依赖伪装为安全的对象级已读集合；本项仅接受 reads=null 并使用 NativeStore 已有 reads=None 保守语义；拒绝客户端自报列表。可信读取会话接入后才开放细粒度合流，不能通过接口注释把不可信声明当成安全证明。

验收：

1. 通过真实 HTTP/ASGI 边界注册两个组织、登录、创建模块、无关模块推进后提交、读取、原子组合及重启回读；不使用 Git 命令、仓库或外部网络。
2. 未登录、过期/撤回会话、伪造 actor/tenant、跨组织摘要访问、严格生产访问控制均有拒绝用例；服务配置不放宽现有认证。
3. 被改模块发生变化时保守拒绝，无关模块变化不要求生产者重做；幂等重试不重复接收，异内容同键拒绝。
4. 非法输入、超限、损坏内容及存储忙正确映射；大请求拒绝尽可能早于全部读入内存，并有真实边界测试。
5. 原生启动路径不构造 Git 队列，旧模式回退仍可启动；原生候选 API 不提供默认批准/检查通过或伪造消费回执。
6. 独立审查、相关已有认证/API 回归及当前服务器隔离测试留证；不更换有效服务，不关闭父目标。

placement=host_tool。输入为明确绝对数据库路径、现有认证身份及受限 JSON 请求；宿主接口为天璇 FastAPI。普通 Python 宿主源不进入引擎逐帧或渲染路径；具体构建影响按真实依赖门禁判断。回退关闭原生挂载/切回既有模式并保留数据库，不能销毁已接收内容。此切片之后仍需可信生产来源、发布审批接线、执行快照和上下文增量、实际消费者及全链路效率对照。
