# 普通游戏项目的编辑器只读审查

稳定需求 ID：`editor-game-independent-review-20261112`；子项 #878，父项 #773。原用户要求完整 Godot 编辑器游戏生产支持，当前根会话承担实现、整合与交付。

## 行为与边界

父会话已关联真实工作区和工单后，`delegate_review` 从宿主实际游戏仓库、项目路径、Git HEAD/分支/common-dir、父会话及快照生成只读委托。调用参数仍仅接受提示与标题，模型不能指定候选或改变绑定。普通游戏委托保存在当前宿主内存，不写入 `engine_candidate`，不创建生产副本，不授予引擎自迭代、写入、命令执行或业务验收权限。

每次审查模型续请求及结果回传重新核对父会话/快照/工单/项目、仓库身份和 HEAD/分支；实际读取文件沿原字节/链接检查。中止撤销委托，冷启动不会从保存字段恢复权限，需在正常父会话重新发起。原引擎候选验证保持生效。

宿主报告真实独立执行上下文：父与审查会话不同；自动验收另列原生产执行/会话标识。此事实只说明宿主隔离的执行身份，不代替审查意见、供应商独立性、候选核验或业务验收。

## 验收

- 普通游戏仓库根及子目录的正式委托、实际只读、父结果回传；零引擎候选或生产执行。
- 源码 HEAD、字节、链接、父工单及绑定漂移不返回有效结果；缺少仓库或未授权父会话不启动。
- 模型提交写入、命令、构建、递归委托、交付及原生修改请求均拒绝；Stop/冷启动不重播。
- 同一二进制保留原引擎审查场景；独立审查、静态检查、严格编译、原生正反例、正式 main 及安装回读。

实现属于现有 native 模块。新测试驱动是测试宿主工具，不是运行时部署模块。构建输入为原生 C++/头文件；实际接口为 `delegate_review`、宿主内存绑定及只读工具。回退为停用普通游戏委托，原生产、回执和引擎审查不迁移或删除。

复用已验证的 `editor-dependency-handoff`：实际读取及候选回读才能接收结果；运输完成和辅助上下文不能替代业务验收。最终真实账号完整生产验收仍由 #773 负责。
