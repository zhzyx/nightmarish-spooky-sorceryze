# D08 保存断线时的文档草稿

在工作台打开「设计文档」，选择文档并点击「编辑正文」。天璇连接中断后，编辑框仍可输入。编辑器在本机保存草稿、编辑起点的完整正文和修订号，并在文档窗口打开期间重试原文档的连接。点击「保留并关闭」后，下次用同一账号、同一业务项目打开此文档，再点「编辑正文」即可恢复。点击「放弃本地草稿」并确认可删除草稿。[原工单 #1746](https://github.com/zhzyx/nightmarish-spooky-sorceryze/issues/1746) · [设计条款](gonggong-ai-workbench-plan1.md#d08)

收到重新认证的文档房间快照后，编辑器比较服务器当前修订号、正文与草稿的编辑起点。若只有 HTTP 服务已恢复，编辑器读取同一账号、项目和文档的当前正文完成比较。两者相同时，可继续编辑并点击「保存」。服务器已变化时，上框保留人的草稿，下框显示服务器完整正文。使用上框编写最终版本，点击「核对两份正文…」、确认后再保存。重连和核对只读，最后一次点击「保存」沿用带目标修订号的条件写入。收到成功回执后清除本地副本。[D07 协作及冲突处理](gonggong-ai-workbench-d07.md)

草稿位于 Godot 编辑器用户数据目录的 `document-drafts/` 下。文件名由天璇服务地址、认证账号 ID、业务项目和文档 ID 的组合计算，持久内容包括基准版本、基准正文及本地编辑。每次输入先写临时文件，成功后重命名替换。恢复入口要求当前服务已允许读取目标文档。新建设计和按固定历史修订打开的引用继续沿用 D04 流程。[D04 编辑入口](gonggong-ai-workbench-d04.md)

## 构建和实测

文档视图和协作适配脚本由 `editor/SCsub` 编入 `BusinessSession.gen.h`，原生侧栏挂载此脚本。更新或回退需运行相应版本的编辑器。服务沿用现有的天璇文档及 WebSocket 接口。

在安装天璇服务依赖（含 WebSocket 支持）的 Python 环境中运行以下命令。探针使用临时数据库和私有 headless 编辑器，关闭实际回环服务，验证 HTTP 无法访问时输入的正文，再在同一地址恢复服务。三个场景覆盖原修订、另一账号已经推进的修订和仅恢复 HTTP。服务器已推进时另经账号、项目、同名文档切换和编辑器进程重启，最后确认比较结果并核对实际写入。[定向验证回执](../data-collection/gonggong-ai-workbench-plan1-d08.json)

```sh
python tests/editor/run_workbench_offline_document.py --godot <候选编辑器> --report <回执路径>
```
