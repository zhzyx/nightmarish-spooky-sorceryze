# E02 识别文档的人工作者修订

工作台编辑已有文档，在保存成功后将版本引用放入发起保存的模块草稿。发送消息时，服务重新核对文档读权，用文曲记录的作者、相邻两版正文和各版的段落编号生成修改清单。已删除的段落保留原编号。保存响应到达前切换账号或模块时，新的草稿不会接收旧模块的内容。

Mac 原生探针通过编辑窗口修改第二段，连续保存 v2 和 v3，发送下一轮消息，然后核对认证服务及模型请求里的前后文、段号、作者和版本。模型传输使用本地替身。[设计条款](gonggong-ai-workbench-plan1.md#e02) · [实际回执](../data-collection/gonggong-ai-workbench-plan1-e02.json)
