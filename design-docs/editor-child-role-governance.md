# 绑定编辑器生产与只读审查子会话的实际职责和治理委托

绑定实际工单、角色、父委托、授权和回执。生产子会话不以设计者冒名实施；独立审查记录真实审查范围及独立性未知，保持只读限制。验证串行、咨询与现有宿主兼容。关联阎罗工单 #671。

## 工单 #676 验收范围

- 编辑器串行设计子工单与手动生产子会话沿真实父工单取得司南协调上下文。宿主将执行者记为 `godot-editor-worker`，记录父子会话、授权来源、工单序号及委托范围摘要。每轮回读绑定后才发送模型请求。
- 父会话委托的只读审查使用其已核验的治理上下文摘要与候选绑定。宿主保存派发时的 HEAD、已读候选相对路径、原始文件字节与返回内容的独立摘要，以及请求的行范围。回传前在原工作树核对工单、分支、提交和每份已读文件。提交变化、已读字节变化或链接重定向会使回传失效，保留原始报告，并提示父会话重新发起审查。每份审查回执标记独立性未知，业务验收由有权责任者核对。
- 验证使用桥接测试和 `tests/editor/run_design_batch.py` 的 normal、review、consultation 场景。另用 review-stale-head、review-stale-bytes 与 review-stale-link 验证同分支前进、节选范围外内容变化及路径重定向。审查场景包含只读工具拒绝、父会话回传及已有历史记录恢复。来源和实际验证结果见 `data-collection/editor-child-role-governance-676.json`，路径基准为仓库根。
