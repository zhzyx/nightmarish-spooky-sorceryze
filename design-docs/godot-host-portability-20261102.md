# 引擎迁移与跨宿主接入

需求标识：`godot-host-portability-20261102`。工单使用 GitHub Issue，唯一类别标签为 `type:bug`。

用户确认把本地引擎安装迁入本仓库 `project/godot`，保留现有源码结构，修复生产 AI 聊天不可启用的原因，并使 Olympus 可适配不同 IDE 和生产工具。继承已有独立审查授权，最终准入批准仍由用户作出。共工框架本体不在本仓库提交范围内。

## 布局与行为

原独立 Godot 安装移动至 `project/godot/versions/godot-4.7.2`，迁移前后逐文件 SHA256 校验；Olympus 定制引擎编译并安装到 `project/godot/bin`。源码保留在仓库根，框架唯一根为 `Olympus/`。安装脚本生成相对路径清单，二进制、构建缓存及机器配置不进入源码 Git。仓库保留完整可构建源码、安装/启动脚本和可运行示例。

编辑器根据可执行文件祖先目录发现工作区，不依赖旧安装深度或当前目录；Olympus 面板和聊天从所选工作区调用同一桥接入口。启动器默认使用新安装位置。跨宿主协议明确 host 身份归属、Agent、真实任务与权限状态，共享正式上下文加载及赫尔墨斯回执；不能通过 host 改名越过准入。

新增 doctor 诊断分别报告 Node、候选完整性、正式上游与框架准入、三个本地 Agent 通行证、赫尔墨斯文件数据。`check` 仍仅候选检查；`context_ready` 仅代表上下文及回执成功，不冒充模型执行。

## 生产阻断的真实根因

上游 yanshi 的只读参考路径和 kuafu 的质量来源路径已迁为相对路径，旧批准摘要未随真实新批准更新。独立审查确认仅这两份文件变化，原件与 6 份质量模板均校验通过。正式加载仍正确报 `Admission subject mismatch`。本地 Athena、Themis、Hermes 的通行证均待批准。

没有发现共享框架依赖特定 IDE/聊天 ID 的准入白名单；原 Godot 适配层硬编码 Godot/Athena 已泛化为宿主协议。历史审查者标识属于真实证据，保留原貌。

## 验收与边界

验证迁移摘要、安装路径发现、示例运行、原生聊天回归、上下文拒绝时零模型请求、取消与恢复、跨宿主/替代注册 Agent、未知身份拒绝及真实数据校验。成功路径使用隔离传输夹具；不把夹具批准或模型回包写成生产事实。

正式生产启用需先批准上游两个精确候选，再按完整同步重建 Olympus 并独立复核最终摘要，最后批准本地准入。源批准证据变化会使本地摘要变化，不用旧摘要替代最终对象。实现提交和 Git 同步不表示已获得这些批准。
