## 接入与验收

1. Windows Godot 编辑器中的天璇页签，以原生 WebView2 控制器承载完整网站，沿现有界面配置来源、前进/后退、刷新/重试。使用当前用户独立数据目录持久化站点会话，不在 URL、日志或仓库记录凭据。
2. 复用已审查的 WebPlatformNative 接口与来源校验；主/子框架、新窗口、重定向和下载遵循同源规则，无任意宿主执行桥。地址配置仍禁止凭据与登录参数。
3. HWND 子视图在布局、缩放、页签隐藏、模态窗口及关闭时保持正确生命周期；异步创建迟到、加载中销毁和浏览器进程退出不得访问已销毁宿主。隐藏和销毁不抢占用户桌面。
4. 固定官方 WebView2 SDK/loader 版本、来源、摘要与许可证。架构对应依赖随 Windows 编辑器分发；运行时缺失和初始化失败有可见诊断及明确重试，不自动安装系统软件或无限重启。
5. Windows 远端 CI 实际编译，并尽可能用隐藏 HWND / 本机测试服务验证真实 WebView2 页面、持久化、导航限制、大小/可见性及销毁。真实显示器键盘/输入法/系统文件面板按仓库静默约定保留给人工验收，不伪称通过。
6. 独立审查、正式门禁、精确候选 CI、PR/main 回读；父单完整验收另行核对，当前子项不以 macOS 的通过替代 Windows。
