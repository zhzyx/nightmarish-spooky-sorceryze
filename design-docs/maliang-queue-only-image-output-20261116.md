## 需求与范围

用户明确要求生图节点的**输出端口／输出结果**是图片队列，而非单张图，以支持多视角、局部细节等结果。本单只改变新节点的输出契约及必要预览、连线和兼容逻辑，不包含其他提示词表单、预览最大化或退出泄漏修复。

## 实现

- 新建文生图、图生图节点使用版本 3，唯一输出为有序 `image_set`，不再暴露单图 `result`。
- 每个数量／视角／变体标签仍对应独立生成子任务；全部成员校验成功后发布队列，不把多视图拼板算作多张输出。
- 版本 3 图生图可接收完整队列；队列不能静默转成单张 Mesh 输入。
- 预览未指定成员时确定性打开首项，仍可逐张切换、校验成员身份和发布。
- 版本 2 保留“主图＋队列”双输出，版本 1 保留单图；未显式记录版本的历史工作流按版本 2 读取，不按新定义重解释。
