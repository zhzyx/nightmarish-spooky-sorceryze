# 工单对话侧栏与可操作节点

关联 #537。用户在 #534 截图中发现推进对话占用整个工作区，当前工作者的等待状态有高亮，真正可以操作的司南按钮却呈灰色。独立的执行预检错误见 #535，切换工单和返回总览性能见 #533。

推进对话应在同一工作区右侧打开，保留工单图、导航和当前选区。支持拖动分隔线调整宽度、在侧栏标题处收起，并能回到同一对话。切换工单继续执行原有的账号、工单和会话绑定检查。

以能否执行具体操作决定提醒位置。需要输入或作决定的实际按钮、选项或文本框为亮绿并有亮白色描边。通过后仍能回访或修改的控件使用浅绿色并带描边。等待远端回执只显示状态。禁用、无权限和只读的控件保留相应语义。

验收覆盖原生桌面左右分栏、收起后原卡片身份、打开会话后切换工单、待输入及已通过的控件、纯等待状态，以及鼠标和键盘使用。
