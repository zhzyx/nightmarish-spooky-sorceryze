## 首版本机实现与能力边界

入口在默认工作台 `HairPanel`，由 `workbench.gd` 创建，带内嵌角色预览。先加载带 FaceBinding 的独立角色基体，再选择毛发来源清单并绑定。修改 face_width/jaw_width 会从当前实际变形头皮重新采样发根，静止 scalp revision 改变使旧绑定失效；逐帧表情的 pose revision 不触发静态重绑。面板支持 Mesh、作者制作的 Guide Cards、三级 LOD、局部冠部帽子遮罩和独立版本保存。原 Rain 静态头发显式隐藏，并保留隐藏原因及原始资源。

独立来源使用已有本机 AI 链路真实生成，未把 Rain 头发改名：

- 图像 run `10786138a4664798885053b479d9310b`，SHA256 `8050380f6996358ca18088f0200ca4328d4ce1e64aa0371c2b5c55363b6a0d4b`。
- 明确选取原图右半矩形 `[256,0,512,512]`，白底等比准备图 SHA256 `27ab5b3d5cd1f9314f979b3956bfce6a7ee51005dac40bfd85e059e6034b3c9c`；原准备回执保留裁剪选择。
- 纯 image-to-mesh run `b40454cf1f5347e7a8dd43391348bc2d`，GLB SHA256 `dbe21df1af13f4df0e21545bf7435eac4e88f71b0955bea99840ddf65d42ddab`。源有 167567 顶点、361668 三角形，补出了不需要的人脸，因此整件拒收。
- `tools/ainative/hair_select.py` 在 Blender 4.5.3 中沿原 GLB 的 +Z 后视方向首命中采样。原坐标 Y-up，显示变换 `(x,-z,y)`。每个派生点保留源 triangle ID 和 barycentric，25×33 的开放后发表面不是自动语义分割结果。初次边界采样失败保留为 selection-v1。selection-v2 虽位于源曲面，但独立审查发现下缘跨洞命中深层面，撤回其完全排除内层/下方破损的结论；v3 仅收窄仍有尖刺，也不作为最终来源。selection-v5 将原 Y 范围截为 [-0.19,0.91] 并收窄下缘，原 GLB 不改写，825 点保持原三角映射。邻格深度跳变水平 0.0328711、竖直 0.0427227，生成器超过 0.06 即拒绝。v4 与 v5 几何相同，v5 增加边界/连续性回执；后、侧、内侧和仰视图供独立复核，不以 on-surface 数值证明代替语义检查。

这是受控后发型：后发表面由生成来源采样适配，冠部发帽由当前头皮三角形明确裁剪、插值和外扩制作，另存原 scalp triangle IDs。Cards 是沿这些 Guide 制作的实心条带代理；不是原模型精细毛丝，也不声称已实现透明纤维纹理或 Strands。原生成底部破洞/层纹没有被包装成干净原网格；适配面片长度收短，原来源及选择证据保留。发根通过最近头皮三角形连续投影，记录 triangle ID、barycentric、参考顶点和位置；根端位于作者 cap 下方，后段渐出，避免最近顶点离散吸附造成浮缝。首版仅支持该显式映射头部，未知头皮资产拒绝；不声称任意生成 Groom 或生产级写实发型。

`hair_runtime.gd` 创建独立 HairGuideBones，根部随身体 head 最终姿态，末端弹簧阻尼在身体之后更新。只写辅助骨，不改 head/neck 或身体骨数量。平移惯性限幅、稳定 dt、瞬移与长帧重置；头、颈和双上臂位置生成碰撞球，末端投影分离。该首版是有限 Guide 端点动力学与线性蒙皮，不是逐毛丝、自碰撞或连续体仿真。LOD 降低 Guide 面片密度；帽子只去除冠部区域，后发保留。辅助骨架用布尔 `ainative_auxiliary_skeleton=true` 与 role `hair-guides-v1` 标记，Interop 只排除明确标记，剩余身体骨架仍须唯一。

重新绑定从本机 locator 检查选择面片 SHA、原生成 Mesh SHA，并解析原 GLB 验证每个 source triangle/barycentric 及重建坐标。保存内嵌已验证来源记录、派生几何、Guide、头皮引用与不含 locator 的逻辑 digest；绝对源路径不进入版本文件。源副本临时移走后仍可重开回放，重新采样/改脸型需重新选择与 SHA 匹配的原始来源，缺源时保留有效实例。加载前预验布局、有限坐标、LOD/布尔选项、根索引、帽面索引、scalp revision 和 binding digest。非法来源、错误 SHA、旧绑定拒绝时保留当前有效角色。保存使用既有 `interop_publish.py` 不覆盖发布边界；重开恢复来源、绑定和分级状态。普通面板显示可操作状态，发布技术错误写日志。
