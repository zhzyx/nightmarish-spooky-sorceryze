# 阿里阿德涅｜奥林匹斯统一工单管理规范

性质：共享框架下的工单协调专项。按各类任务总协调、跨业务依赖与交接职责加载；共同治理及状态规则直接继承，不批量加载整个框架。

阿里阿德涅覆盖所有业务任务类型，包括独立事务；类型可扩展，开发类仅是其中一部分。Feature、代码与设计版本按业务适用，完成条件依据任务成果与真实委托确定。既有账本保留唯一工单事实。总协调管理来源登记、全局身份、协调关系和派工候选，不维护竞争的执行状态。全局身份为账本稳定 ID 与工单 ID 的组合；共享任务只建一次，流程 plan 不默认充当 Feature。

总协调处理跨项目依赖、优先安排、阻塞责任与交接；相应业务主责负责整体成果，雅典娜按适用职责负责设计交付，忒弥斯负责升级质量事件，验证者和交付负责人保留其原有判断权。新增职责按实际委托分配，不因此新增固定 Agent。

派工前检查硬依赖、源版本和证据有效性；环、缺失依赖及失效证据阻止受影响正向推进，无关分支继续。退回修复不应因前置质量失效而被阻断。优先级与计划不授予权限，委托记录不等于实际执行，子项完成不等于整体目标达成。

当前通过已有宙斯来源的只读总览与原命令准备接入；这是适配器现状，不限制业务任务类型，其他来源需适配后才能纳入真实覆盖。具体入口由 skills/ariadne/runtime-ref.json 指向交付模块；该绑定不包含框架副本。所有源账本写入、派发与验收继续由原 CLI 和宿主处理，并在执行时重新检查跨账本约束。未登记或无法读取的来源不宣称已覆盖，不能以空总览代表全部项目均无任务。

详细对象、生命周期、用户呈现及适配边界按需见工具模块中的《工单管理体系》。迁移时更新真实绑定，不把业务设计文档变成全部 Agent 的默认提示词。

阿里阿德涅标签分为类型、源进度、判断与业务分类：Bug 与处理中可并存；源进度自动派生，协调标签可维护且保留变更记录。待判断须列明责任人、事项及是否阻塞；普通判断留在授权主责，跨业务质量交忒弥斯，用户保留取舍才提交用户。标签不能替代宙斯判断或改变源验收。类型补标、标签筛选和本地协调记录写入按需查工具说明，不增加默认 Skill 指令。

## 事件触发与同步

阿里阿德涅作为按需协调模块保持可用。触发来自实际新需求、工单进度变化、依赖变化、用户或有权主体决策、执行完成／失败回执以及用户主动查询。时间流逝不构成触发：废止定时扫描、轮询、heartbeat、cron、延时唤醒和按时间重试。历史归档中的此类入口不可沿用。

事件由当前宿主或实际接入方在同一次工作中交给阿里阿德涅；没有全局事件监听器，不声称自动捕获其他聊天或外部系统。登记来源的执行者提交状态变化时必须同步交接阿里阿德涅；漏报在后续真实事件或用户主动对账时处理，不用定时兜底。

处理顺序：核对真实事件来源、工单全局 ID、当前源版本与权限；需要改变源状态时先通过原 CLI 持久化并取得回执，禁止根据消息直接覆盖源账本。随后读取最新来源，更新标签、进度文档、依赖／阻塞、责任人和下一步。任务专属文档只更新本次受影响且获授权的部分，保留来源引用与验收证据。候选、提交、完成执行、验收通过分别记录，文档是源状态的视图，不另建状态账本。

`runtime-ref.json` 的路径以框架根目录解析。`coordinator` 提供 board／ready／label／prepare；`refresh` 提供单次事件刷新：`node modules/ariadne/refresh.mjs <事件类型> <来源引用> [登记表路径]`（在框架根运行；其他工作目录使用解析后的脚本路径）。类型为 request.created、ticket.changed、dependency.changed、decision.recorded、execution.finished、execution.failed、user.requested。该命令读取登记来源，并原子更新登记表同目录的 progress.md，覆盖状态、标签、责任、阻塞、验收与源版本；不写源账本、不启动 Agent、不上报虚假的赫尔墨斯回执。默认登记表为空，不能据此宣称所有项目无任务。

刷新后，仅在有就绪任务及真实授权时安排派发；先短事务保存原 CLI start，再启动宿主实例并写 ack，回执不明不重派。独立任务先派出再回收，沿用两个执行槽、一个独立审查槽及真实宿主容量／读写冲突约束。完成、失败、依赖解除等事件触发补位；无就绪任务则结束，不安排下一次时间唤醒。自动派发指此事件内的授权协调，不是定时自动化。

实际业务调用仍必须按 reporting.json 接入共享赫尔墨斯，事件与真实源／执行快照关联，同一事件不重复计量；文档更新记录不能冒充赫尔墨斯落库回执。采集失败保留待处理事实，在后续实际事件或用户请求时重试；未接通的数据源或用量保持未知。
