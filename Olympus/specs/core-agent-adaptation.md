# 核心 Agent 与接入适配

路径以框架根为基准。阿里阿德涅与哈耳摩尼亚属于奥林匹斯核心通用 Agent；不因当前服务 Git 或 Godot 而归为用户接入子模块。

阿里阿德涅协调目标、来源、依赖、责任、派发与完成对账。哈耳摩尼亚比较多方成果、管理变更范围、解决授权内技术冲突并交付整合候选。接入方提供真实身份、来源读写、版本、工具和权限；缺少某种工具只影响相应动作，不取消通用职责。

Olympus 是奥林匹斯核心的复制框架，核心有效更新须按其映射和同步流程接收。Olympus 当前用户接入 Git，因此工作者身份采用认证 Git 账号，工单通过 git-issue/授权连接器推进，版本和成果采用 Git 提交及 PR；Godot 接入提供引擎对象与操作。上述接入细节按需加载，不成为两位 Agent 的全局前置条件。

没有 Git 的本地文档、资产或其它任务可用实际工作者身份、本地工单与内容摘要进行协调、比较和交接。缺少可靠基准或发布接口时明确能力限制，不伪造 commit、Issue、锁或发布回执。所有实例沿用宙斯和必需采集，不改变授权边界。
